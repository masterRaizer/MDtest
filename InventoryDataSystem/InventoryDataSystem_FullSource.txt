================================================================================
 INVENTORY DATA SYSTEM для Unreal Engine 4 (4.26 / 4.27)
 Полный исходный код и инструкция по установке — в одном файле
================================================================================

СОДЕРЖАНИЕ
  1. Инструкция по установке (как разложить файлы)
  2. Структура папок
  3. Исходный код: каждый файл начинается с заголовка "ФАЙЛ: <путь>"
  4. Документация (README)

================================================================================
 1. ИНСТРУКЦИЯ ПО УСТАНОВКЕ
================================================================================

Шаг 1. Закройте Unreal Editor.

Шаг 2. В корне вашего проекта (там, где лежит файл <ВашПроект>.uproject)
       создайте папку Plugins, если её ещё нет.

Шаг 3. Внутри неё повторите структуру папок из раздела 2:
         <ВашПроект>/Plugins/InventoryData/
         <ВашПроект>/Plugins/InventoryData/Data/
         <ВашПроект>/Plugins/InventoryData/Source/InventoryData/Public/
         <ВашПроект>/Plugins/InventoryData/Source/InventoryData/Private/

Шаг 4. Для каждого блока "ФАЙЛ: ..." из раздела 3:
         - создайте файл с указанным именем по указанному пути
           (путь отсчитывается от папки <ВашПроект>/);
         - скопируйте в него весь текст между строкой "ФАЙЛ: ..."
           и строкой "КОНЕЦ ФАЙЛА";
         - сохраните файл в кодировке UTF-8.
       Имена файлов и папок должны совпадать с указанными до символа:
       Unreal Header Tool ищет файлы *.generated.h по имени заголовка.

Шаг 5. Проекту нужен C++. Если проект чисто Blueprint, сначала добавьте
       любой C++ класс: File → New C++ Class.

Шаг 6. Нажмите правой кнопкой на <ВашПроект>.uproject и выберите
       "Generate Visual Studio project files". Затем откройте .sln
       и соберите проект в конфигурации Development Editor.

Шаг 7. Запустите редактор. Откройте Edit → Plugins, найдите "Inventory Data"
       и убедитесь, что плагин включён.

Шаг 8. Создайте таблицу предметов:
         - Content Browser → правая кнопка → Miscellaneous → Data Table,
           в качестве Row Structure выберите ItemTableRow;
         - либо импортируйте Data/SampleItems.csv: перетащите файл
           в Content Browser и выберите структуру ItemTableRow.
       Пути к иконкам в CSV условные, замените их на свои текстуры.

Шаг 9. Откройте Project Settings → Game → Inventory Data и добавьте
       созданную таблицу в Item Tables.

Шаг 10. Использование:
         - UMG: в палитре, в категории Inventory, есть виджет "Item ComboBox".
         - Ресурсы: добавьте актору компонент "Resource Manager"
           (или Blueprint-наследника с переменными Gold, Wood и т.д.).
         - База предметов: узел Get Game Instance Subsystem →
           ItemDatabaseSubsystem.

ПРИМЕЧАНИЯ
  - UE 4.25: удалите строку "DeveloperSettings" из InventoryData.Build.cs.
  - Код не проверялся компиляцией. При ошибках сборки смотрите сообщение
    компилятора: обычно расхождения между версиями движка небольшие.

#pragma once

INVENTORYDATA_API DECLARE_LOG_CATEGORY_EXTERN(LogInventoryData, Log, All);

UENUM(BlueprintType)
enum class EItemRarity : uint8
{
	Common,
	Uncommon,
	Rare,
	Epic,
	Legendary
};

/**
 * Reference row layout for item DataTables.
 * The parser does not require this exact struct: any row struct works as long as
 * the field names are configured in FItemTableFieldMapping.
 */
USTRUCT(BlueprintType)
struct INVENTORYDATA_API FItemTableRow : public FTableRowBase
{
	GENERATED_BODY()

	/** Unique item ID. If empty, the DataTable row name is used. */
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item")
	FName ItemId;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item")
	FText DisplayName;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item", meta = (MultiLine = true))
	FText Description;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item|Visual")
	TSoftObjectPtr<UTexture2D> Icon;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item|Visual")
	EItemRarity Rarity = EItemRarity::Common;

	/** When false, the color comes from the rarity palette in project settings. */
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item|Visual")
	bool bOverrideColor = false;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item|Visual", meta = (EditCondition = "bOverrideColor"))
	FLinearColor Color = FLinearColor::White;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item", meta = (ClampMin = 1))
	int32 MaxStack = 1;
};

/** Names of the row-struct fields the parser reads. Set a field to None to skip it. */
USTRUCT(BlueprintType)
struct INVENTORYDATA_API FItemTableFieldMapping
{
	GENERATED_BODY()

	/** FName / FString / integer field. Falls back to the row name when missing or empty. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Mapping")
	FName IdField = TEXT("ItemId");

	/** FText / FString / FName field. Falls back to the item ID. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Mapping")
	FName NameField = TEXT("DisplayName");

	/** Soft or hard texture reference, or a string asset path. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Mapping")
	FName IconField = TEXT("Icon");

	/** EItemRarity / any enum / integer / string ("Epic") field. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Mapping")
	FName RarityField = TEXT("Rarity");

	/** FLinearColor or FColor field. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Mapping")
	FName ColorField = TEXT("Color");

	/** Bool gating ColorField. If the row struct has no such field, ColorField always wins over the rarity color. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Mapping")
	FName ColorOverrideField = TEXT("bOverrideColor");
};

/** Visual properties bound to an item ID. */
USTRUCT(BlueprintType)
struct INVENTORYDATA_API FItemVisualData
{
	GENERATED_BODY()

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item|Visual")
	TSoftObjectPtr<UTexture2D> Icon;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item|Visual")
	FLinearColor Color = FLinearColor::White;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item|Visual")
	EItemRarity Rarity = EItemRarity::Common;
};

/** One parsed item: identity, display name and visuals, plus where it came from. */
USTRUCT(BlueprintType)
struct INVENTORYDATA_API FItemDescriptor
{
	GENERATED_BODY()

	UPROPERTY(BlueprintReadOnly, Category = "Item")
	FName ItemId;

	UPROPERTY(BlueprintReadOnly, Category = "Item")
	FText DisplayName;

	UPROPERTY(BlueprintReadOnly, Category = "Item")
	FItemVisualData Visual;

	UPROPERTY(BlueprintReadOnly, Category = "Item")
	UDataTable* SourceTable = nullptr;

	UPROPERTY(BlueprintReadOnly, Category = "Item")
	FName RowName;
};

/** Which items go into a list (ComboBox) and in what order. */
USTRUCT(BlueprintType)
struct INVENTORYDATA_API FItemListFilter
{
	GENERATED_BODY()

	/** Empty = all rarities. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Filter")
	TArray<EItemRarity> AllowedRarities;

	/** Case-insensitive substring matched against display name and ID. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Filter")
	FString SearchText;

	/** Sort by display name; otherwise keep DataTable order. */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Filter")
	bool bSortByName = true;
};

UInventoryDataSettings::UInventoryDataSettings()
{
	RarityColors.Add(EItemRarity::Common, FLinearColor(0.80f, 0.80f, 0.80f));
	RarityColors.Add(EItemRarity::Uncommon, FLinearColor(0.12f, 0.85f, 0.20f));
	RarityColors.Add(EItemRarity::Rare, FLinearColor(0.10f, 0.45f, 1.00f));
	RarityColors.Add(EItemRarity::Epic, FLinearColor(0.64f, 0.21f, 0.93f));
	RarityColors.Add(EItemRarity::Legendary, FLinearColor(1.00f, 0.55f, 0.00f));
}

FLinearColor UInventoryDataSettings::GetRarityColor(EItemRarity Rarity) const
{
	const FLinearColor* Color = RarityColors.Find(Rarity);
	return Color ? *Color : FLinearColor::White;
}

#pragma once

#include "CoreMinimal.h"
#include "UObject/Class.h"
#include "UObject/UnrealType.h"

namespace InventoryReflection
{
	/**
	 * FindPropertyByName that also works for Blueprint (User Defined) structs,
	 * whose real property names are mangled ("Gold_12_8F3A...") — those are matched by authored name.
	 */
	inline FProperty* FindPropertyByAuthoredName(const UStruct* Struct, FName Name)
	{
		if (!Struct || Name.IsNone())
		{
			return nullptr;
		}
		if (FProperty* Property = Struct->FindPropertyByName(Name))
		{
			return Property;
		}
		const FString Wanted = Name.ToString();
		for (TFieldIterator<FProperty> It(Struct); It; ++It)
		{
			if (Struct->GetAuthoredNameForField(*It).Equals(Wanted, ESearchCase::IgnoreCase))
			{
				return *It;
			}
		}
		return nullptr;
	}
}

#pragma once

#include "CoreMinimal.h"
#include "InventoryTypes.h"

class UDataTable;

/**
 * Stateless reader of item DataTables. Reads rows through the reflection system,
 * so it works with any row struct (C++ or Blueprint) given a field mapping.
 * Has no world dependency: usable at runtime, in the editor and in the UMG designer.
 */
class INVENTORYDATA_API FItemDatabaseParser
{
public:
	/** Appends the items of one table to OutItems. IDs already in InOutSeenIds are skipped. Returns the number added. */
	static int32 ParseTable(UDataTable& Table, const UInventoryDataSettings& Settings,
		TArray<FItemDescriptor>& OutItems, TSet<FName>& InOutSeenIds, TArray<FString>* OutWarnings = nullptr);

	static TArray<FItemDescriptor> ParseTables(const TArray<UDataTable*>& Tables, const UInventoryDataSettings& Settings,
		TArray<FString>* OutWarnings = nullptr);

	/** Synchronously loads the tables listed in project settings. */
	static TArray<UDataTable*> LoadConfiguredTables(const UInventoryDataSettings& Settings);

	/** Item IDs from the configured tables, for meta=(GetOptions=...) dropdowns in the Details panel. */
	static TArray<FString> GetConfiguredItemIdOptions();

	/** Replaces {Name}, {Id} and {Rarity} in Format. */
	static FString FormatLabel(const FString& Format, const FItemDescriptor& Item);

	/** One label per item (same order), with " (Id)" appended on collisions so every label maps to exactly one item. */
	static TArray<FString> BuildUniqueLabels(const TArray<FItemDescriptor>& Items, const FString& Format);

	/** Indices of the items that pass the filter, in display order. */
	static TArray<int32> SelectItems(const TArray<FItemDescriptor>& Items, const FItemListFilter& Filter);
};

////////////////////////////////////////////////////////////////////////////////
// ФАЙЛ: Plugins/InventoryData/Source/InventoryData/Private/ItemDatabaseParser.cpp

#include "ItemDatabaseParser.h"

#include "Algo/Sort.h"
#include "Engine/DataTable.h"
#include "InventoryDataSettings.h"
#include "InventoryReflectionUtils.h"

namespace ItemParserPrivate
{
	bool ReadName(const FProperty* Property, const void* Row, FName& Out)
	{
		if (const FNameProperty* NameProp = CastField<FNameProperty>(Property))
		{
			Out = NameProp->GetPropertyValue_InContainer(Row);
		}
		else if (const FStrProperty* StrProp = CastField<FStrProperty>(Property))
		{
			const FString& Value = StrProp->GetPropertyValue_InContainer(Row);
			Out = Value.IsEmpty() ? NAME_None : FName(*Value);
		}
		else if (const FNumericProperty* NumProp = CastField<FNumericProperty>(Property))
		{
			if (!NumProp->IsInteger() || NumProp->IsEnum())
			{
				return false;
			}
			Out = FName(*LexToString(NumProp->GetSignedIntPropertyValue(NumProp->ContainerPtrToValuePtr<void>(Row))));
		}
		return !Out.IsNone();
	}

	bool ReadText(const FProperty* Property, const void* Row, FText& Out)
	{
		if (const FTextProperty* TextProp = CastField<FTextProperty>(Property))
		{
			Out = TextProp->GetPropertyValue_InContainer(Row);
		}
		else if (const FStrProperty* StrProp = CastField<FStrProperty>(Property))
		{
			Out = FText::FromString(StrProp->GetPropertyValue_InContainer(Row));
		}
		else if (const FNameProperty* NameProp = CastField<FNameProperty>(Property))
		{
			Out = FText::FromName(NameProp->GetPropertyValue_InContainer(Row));
		}
		return !Out.IsEmpty();
	}

	bool ReadAssetPath(const FProperty* Property, const void* Row, FSoftObjectPath& Out)
	{
		// Soft references are checked first: FSoftObjectProperty derives from FObjectPropertyBase.
		if (const FSoftObjectProperty* SoftProp = CastField<FSoftObjectProperty>(Property))
		{
			Out = SoftProp->GetPropertyValue_InContainer(Row).ToSoftObjectPath();
		}
		else if (const FObjectPropertyBase* ObjectProp = CastField<FObjectPropertyBase>(Property))
		{
			if (UObject* Object = ObjectProp->GetObjectPropertyValue_InContainer(Row))
			{
				Out = FSoftObjectPath(Object);
			}
		}
		else if (const FStrProperty* StrProp = CastField<FStrProperty>(Property))
		{
			Out = FSoftObjectPath(StrProp->GetPropertyValue_InContainer(Row));
		}
		return Out.IsValid();
	}

	bool ReadRarity(const FProperty* Property, const void* Row, EItemRarity& Out)
	{
		int64 Raw = INDEX_NONE;
		if (const FEnumProperty* EnumProp = CastField<FEnumProperty>(Property))
		{
			Raw = EnumProp->GetUnderlyingProperty()->GetSignedIntPropertyValue(EnumProp->ContainerPtrToValuePtr<void>(Row));
		}
		else if (const FNumericProperty* NumProp = CastField<FNumericProperty>(Property))
		{
			if (NumProp->IsInteger())
			{
				Raw = NumProp->GetSignedIntPropertyValue(NumProp->ContainerPtrToValuePtr<void>(Row));
			}
		}
		else
		{
			FName AsName;
			if (ReadName(Property, Row, AsName))
			{
				Raw = StaticEnum<EItemRarity>()->GetValueByNameString(AsName.ToString());
			}
		}

		if (Raw < 0)
		{
			return false;
		}
		// Values of a foreign enum with more entries are clamped to the highest rarity.
		Out = static_cast<EItemRarity>(FMath::Min<int64>(Raw, static_cast<int64>(EItemRarity::Legendary)));
		return true;
	}

	bool ReadColor(const FProperty* Property, const void* Row, FLinearColor& Out)
	{
		const FStructProperty* StructProp = CastField<FStructProperty>(Property);
		if (!StructProp)
		{
			return false;
		}
		const void* Value = StructProp->ContainerPtrToValuePtr<void>(Row);
		if (StructProp->Struct == TBaseStructure<FLinearColor>::Get())
		{
			Out = *static_cast<const FLinearColor*>(Value);
			return true;
		}
		if (StructProp->Struct == TBaseStructure<FColor>::Get())
		{
			Out = FLinearColor(*static_cast<const FColor*>(Value));
			return true;
		}
		return false;
	}

	bool ReadBool(const FProperty* Property, const void* Row, bool& Out)
	{
		if (const FBoolProperty* BoolProp = CastField<FBoolProperty>(Property))
		{
			Out = BoolProp->GetPropertyValue_InContainer(Row);
			return true;
		}
		return false;
	}

	const FProperty* FindMappedField(const UScriptStruct* RowStruct, FName FieldName, const UDataTable& Table, TArray<FString>* OutWarnings)
	{
		const FProperty* Property = InventoryReflection::FindPropertyByAuthoredName(RowStruct, FieldName);
		if (!Property && !FieldName.IsNone() && OutWarnings)
		{
			OutWarnings->Add(FString::Printf(TEXT("%s: row struct %s has no field '%s'"),
				*Table.GetName(), *RowStruct->GetName(), *FieldName.ToString()));
		}
		return Property;
	}
}

int32 FItemDatabaseParser::ParseTable(UDataTable& Table, const UInventoryDataSettings& Settings,
	TArray<FItemDescriptor>& OutItems, TSet<FName>& InOutSeenIds, TArray<FString>* OutWarnings)
{
	using namespace ItemParserPrivate;

	const UScriptStruct* RowStruct = Table.GetRowStruct();
	if (!RowStruct)
	{
		if (OutWarnings)
		{
			OutWarnings->Add(FString::Printf(TEXT("%s: DataTable has no row struct"), *Table.GetName()));
		}
		return 0;
	}

	const FItemTableFieldMapping& Mapping = Settings.FieldMapping;
	// A missing ID field is not an error: row names are a valid ID source.
	const FProperty* IdProp = FindMappedField(RowStruct, Mapping.IdField, Table, nullptr);
	const FProperty* NameProp = FindMappedField(RowStruct, Mapping.NameField, Table, OutWarnings);
	const FProperty* IconProp = FindMappedField(RowStruct, Mapping.IconField, Table, OutWarnings);
	const FProperty* RarityProp = FindMappedField(RowStruct, Mapping.RarityField, Table, OutWarnings);
	const FProperty* ColorProp = FindMappedField(RowStruct, Mapping.ColorField, Table, nullptr);
	const FProperty* ColorOverrideProp = FindMappedField(RowStruct, Mapping.ColorOverrideField, Table, nullptr);

	int32 NumAdded = 0;
	for (const TPair<FName, uint8*>& RowPair : Table.GetRowMap())
	{
		const void* Row = RowPair.Value;

		FItemDescriptor Item;
		Item.RowName = RowPair.Key;
		Item.SourceTable = &Table;

		if (!ReadName(IdProp, Row, Item.ItemId))
		{
			Item.ItemId = RowPair.Key;
		}
		if (InOutSeenIds.Contains(Item.ItemId))
		{
			if (OutWarnings)
			{
				OutWarnings->Add(FString::Printf(TEXT("%s: duplicate item ID '%s' in row '%s', skipped"),
					*Table.GetName(), *Item.ItemId.ToString(), *RowPair.Key.ToString()));
			}
			continue;
		}

		if (!ReadText(NameProp, Row, Item.DisplayName))
		{
			Item.DisplayName = FText::FromName(Item.ItemId);
		}

		FSoftObjectPath IconPath;
		if (ReadAssetPath(IconProp, Row, IconPath))
		{
			Item.Visual.Icon = TSoftObjectPtr<UTexture2D>(IconPath);
		}

		ReadRarity(RarityProp, Row, Item.Visual.Rarity);
		Item.Visual.Color = Settings.GetRarityColor(Item.Visual.Rarity);

		bool bUseRowColor = true;
		ReadBool(ColorOverrideProp, Row, bUseRowColor);
		FLinearColor RowColor;
		if (bUseRowColor && ReadColor(ColorProp, Row, RowColor))
		{
			Item.Visual.Color = RowColor;
		}

		InOutSeenIds.Add(Item.ItemId);
		OutItems.Add(MoveTemp(Item));
		++NumAdded;
	}
	return NumAdded;
}

TArray<FItemDescriptor> FItemDatabaseParser::ParseTables(const TArray<UDataTable*>& Tables, const UInventoryDataSettings& Settings,
	TArray<FString>* OutWarnings)
{
	TArray<FItemDescriptor> Items;
	TSet<FName> SeenIds;
	for (UDataTable* Table : Tables)
	{
		if (Table)
		{
			ParseTable(*Table, Settings, Items, SeenIds, OutWarnings);
		}
	}
	return Items;
}

TArray<UDataTable*> FItemDatabaseParser::LoadConfiguredTables(const UInventoryDataSettings& Settings)
{
	TArray<UDataTable*> Tables;
	for (const TSoftObjectPtr<UDataTable>& TableRef : Settings.ItemTables)
	{
		if (UDataTable* Table = TableRef.LoadSynchronous())
		{
			Tables.AddUnique(Table);
		}
		else if (!TableRef.IsNull())
		{
			UE_LOG(LogInventoryData, Warning, TEXT("Item table '%s' could not be loaded"), *TableRef.ToString());
		}
	}
	return Tables;
}

TArray<FString> FItemDatabaseParser::GetConfiguredItemIdOptions()
{
	const UInventoryDataSettings& Settings = *GetDefault<UInventoryDataSettings>();
	TArray<FString> Options;
	for (const FItemDescriptor& Item : ParseTables(LoadConfiguredTables(Settings), Settings))
	{
		Options.Add(Item.ItemId.ToString());
	}
	Options.Sort();
	return Options;
}

FString FItemDatabaseParser::FormatLabel(const FString& Format, const FItemDescriptor& Item)
{
	const FString RarityName = StaticEnum<EItemRarity>()->GetNameStringByValue(static_cast<int64>(Item.Visual.Rarity));
	return Format
		.Replace(TEXT("{Name}"), *Item.DisplayName.ToString())
		.Replace(TEXT("{Id}"), *Item.ItemId.ToString())
		.Replace(TEXT("{Rarity}"), *RarityName);
}

TArray<FString> FItemDatabaseParser::BuildUniqueLabels(const TArray<FItemDescriptor>& Items, const FString& Format)
{
	TArray<FString> Labels;
	Labels.Reserve(Items.Num());
	TSet<FString> Used;
	for (const FItemDescriptor& Item : Items)
	{
		FString Label = FormatLabel(Format, Item);
		if (Label.IsEmpty() || Used.Contains(Label))
		{
			// IDs are unique, so suffixing the ID resolves the collision.
			Label += FString::Printf(TEXT(" (%s)"), *Item.ItemId.ToString());
		}
		Used.Add(Label);
		Labels.Add(MoveTemp(Label));
	}
	return Labels;
}

TArray<int32> FItemDatabaseParser::SelectItems(const TArray<FItemDescriptor>& Items, const FItemListFilter& Filter)
{
	TArray<int32> Indices;
	for (int32 Index = 0; Index < Items.Num(); ++Index)
	{
		const FItemDescriptor& Item = Items[Index];
		if (Filter.AllowedRarities.Num() > 0 && !Filter.AllowedRarities.Contains(Item.Visual.Rarity))
		{
			continue;
		}
		if (!Filter.SearchText.IsEmpty()
			&& !Item.DisplayName.ToString().Contains(Filter.SearchText)
			&& !Item.ItemId.ToString().Contains(Filter.SearchText))
		{
			continue;
		}
		Indices.Add(Index);
	}

	if (Filter.bSortByName)
	{
		Algo::Sort(Indices, [&Items](int32 A, int32 B)
		{
			return Items[A].DisplayName.CompareTo(Items[B].DisplayName) < 0;
		});
	}
	return Indices;
}

void UItemDatabaseSubsystem::Initialize(FSubsystemCollectionBase& Collection)
{
	Super::Initialize(Collection);

#if WITH_EDITOR
	GetMutableDefault<UInventoryDataSettings>()->OnSettingChanged().AddUObject(this, &UItemDatabaseSubsystem::HandleSettingsChanged);
#endif

	RebuildDatabase();
}

void UItemDatabaseSubsystem::Deinitialize()
{
	UnbindTableChangeDelegates();
#if WITH_EDITOR
	GetMutableDefault<UInventoryDataSettings>()->OnSettingChanged().RemoveAll(this);
#endif

	Super::Deinitialize();
}

void UItemDatabaseSubsystem::RebuildDatabase()
{
	const UInventoryDataSettings& Settings = *GetDefault<UInventoryDataSettings>();

	UnbindTableChangeDelegates();
	ActiveTables = FItemDatabaseParser::LoadConfiguredTables(Settings);
	for (UDataTable* Table : RuntimeTables)
	{
		if (Table)
		{
			ActiveTables.AddUnique(Table);
		}
	}

	TArray<FString> Warnings;
	Items = FItemDatabaseParser::ParseTables(ActiveTables, Settings, &Warnings);
	for (const FString& Warning : Warnings)
	{
		UE_LOG(LogInventoryData, Warning, TEXT("%s"), *Warning);
	}

	const TArray<FString> Labels = FItemDatabaseParser::BuildUniqueLabels(Items, Settings.ComboBoxLabelFormat);
	ItemIndexById.Reset();
	VisualById.Reset();
	IdByLabel.Reset();
	LabelById.Reset();
	for (int32 Index = 0; Index < Items.Num(); ++Index)
	{
		const FItemDescriptor& Item = Items[Index];
		ItemIndexById.Add(Item.ItemId, Index);
		VisualById.Add(Item.ItemId, Item.Visual);
		IdByLabel.Add(Labels[Index], Item.ItemId);
		LabelById.Add(Item.ItemId, Labels[Index]);
	}

	BindTableChangeDelegates();

	UE_LOG(LogInventoryData, Log, TEXT("Item database built: %d items from %d tables"), Items.Num(), ActiveTables.Num());
	OnDatabaseRebuilt.Broadcast();
}

void UItemDatabaseSubsystem::RegisterItemTable(UDataTable* Table)
{
	if (Table && !RuntimeTables.Contains(Table))
	{
		RuntimeTables.Add(Table);
		RebuildDatabase();
	}
}

void UItemDatabaseSubsystem::UnregisterItemTable(UDataTable* Table)
{
	if (RuntimeTables.Remove(Table) > 0)
	{
		RebuildDatabase();
	}
}

bool UItemDatabaseSubsystem::FindItem(FName ItemId, FItemDescriptor& OutItem) const
{
	if (const int32* Index = ItemIndexById.Find(ItemId))
	{
		OutItem = Items[*Index];
		return true;
	}
	return false;
}

TArray<FName> UItemDatabaseSubsystem::GetAllItemIds() const
{
	TArray<FName> Ids;
	Ids.Reserve(Items.Num());
	for (const FItemDescriptor& Item : Items)
	{
		Ids.Add(Item.ItemId);
	}
	return Ids;
}

TArray<FItemDescriptor> UItemDatabaseSubsystem::FilterItems(const FItemListFilter& Filter) const
{
	TArray<FItemDescriptor> Result;
	for (int32 Index : FItemDatabaseParser::SelectItems(Items, Filter))
	{
		Result.Add(Items[Index]);
	}
	return Result;
}

bool UItemDatabaseSubsystem::GetItemVisual(FName ItemId, FItemVisualData& OutVisual) const
{
	if (const FItemVisualData* Visual = VisualById.Find(ItemId))
	{
		OutVisual = *Visual;
		return true;
	}
	return false;
}

FLinearColor UItemDatabaseSubsystem::GetItemColor(FName ItemId) const
{
	const FItemVisualData* Visual = VisualById.Find(ItemId);
	return Visual ? Visual->Color : FLinearColor::White;
}

FLinearColor UItemDatabaseSubsystem::GetRarityColor(EItemRarity Rarity) const
{
	return GetDefault<UInventoryDataSettings>()->GetRarityColor(Rarity);
}

UTexture2D* UItemDatabaseSubsystem::LoadItemIcon(FName ItemId) const
{
	const FItemVisualData* Visual = VisualById.Find(ItemId);
	return Visual ? Visual->Icon.LoadSynchronous() : nullptr;
}

void UItemDatabaseSubsystem::RequestItemIconAsync(FName ItemId, TFunction<void(UTexture2D*)> OnLoaded) const
{
	const FItemVisualData* Visual = VisualById.Find(ItemId);
	if (!Visual || Visual->Icon.IsNull())
	{
		OnLoaded(nullptr);
		return;
	}
	if (UTexture2D* Loaded = Visual->Icon.Get())
	{
		OnLoaded(Loaded);
		return;
	}

	TSoftObjectPtr<UTexture2D> Icon = Visual->Icon;
	UAssetManager::GetStreamableManager().RequestAsyncLoad(Icon.ToSoftObjectPath(),
		FStreamableDelegate::CreateLambda([Icon, Callback = MoveTemp(OnLoaded)]()
		{
			Callback(Icon.Get());
		}));
}

int32 UItemDatabaseSubsystem::PopulateComboBox(UComboBoxString* ComboBox, const FItemListFilter& Filter)
{
	if (!ComboBox)
	{
		return 0;
	}

	const FString PreviousSelection = ComboBox->GetSelectedOption();
	ComboBox->ClearOptions();
	for (int32 Index : FItemDatabaseParser::SelectItems(Items, Filter))
	{
		ComboBox->AddOption(LabelById.FindChecked(Items[Index].ItemId));
	}
	if (ComboBox->FindOptionIndex(PreviousSelection) != INDEX_NONE)
	{
		ComboBox->SetSelectedOption(PreviousSelection);
	}
	ComboBox->RefreshOptions();
	return ComboBox->GetOptionCount();
}

FName UItemDatabaseSubsystem::GetItemIdFromLabel(const FString& Label) const
{
	const FName* Id = IdByLabel.Find(Label);
	return Id ? *Id : NAME_None;
}

FString UItemDatabaseSubsystem::GetItemLabel(FName ItemId) const
{
	const FString* Label = LabelById.Find(ItemId);
	return Label ? *Label : FString();
}

void UItemDatabaseSubsystem::BindTableChangeDelegates()
{
#if WITH_EDITOR
	// Live-reload while editing tables during PIE.
	for (UDataTable* Table : ActiveTables)
	{
		Table->OnDataTableChanged().AddUObject(this, &UItemDatabaseSubsystem::HandleTableChanged);
	}
#endif
}

void UItemDatabaseSubsystem::UnbindTableChangeDelegates()
{
#if WITH_EDITOR
	for (UDataTable* Table : ActiveTables)
	{
		if (Table)
		{
			Table->OnDataTableChanged().RemoveAll(this);
		}
	}
#endif
}

void UItemDatabaseSubsystem::HandleTableChanged()
{
	RebuildDatabase();
}

#if WITH_EDITOR
void UItemDatabaseSubsystem::HandleSettingsChanged(UObject* Settings, FPropertyChangedEvent& Event)
{
	RebuildDatabase();
}
#endif

void UItemComboBox::SynchronizeProperties()
{
	Super::SynchronizeProperties();

	OnSelectionChanged.AddUniqueDynamic(this, &UItemComboBox::HandleSelectionChanged);
	if (UItemDatabaseSubsystem* Database = GetDatabase())
	{
		Database->OnDatabaseRebuilt.AddUniqueDynamic(this, &UItemComboBox::HandleDatabaseRebuilt);
	}

	RefreshItems();
}

void UItemComboBox::ReleaseSlateResources(bool bReleaseChildren)
{
	if (UItemDatabaseSubsystem* Database = GetDatabase())
	{
		Database->OnDatabaseRebuilt.RemoveDynamic(this, &UItemComboBox::HandleDatabaseRebuilt);
	}

	Super::ReleaseSlateResources(bReleaseChildren);
}

#if WITH_EDITOR
const FText UItemComboBox::GetPaletteCategory()
{
	return LOCTEXT("InventoryPaletteCategory", "Inventory");
}
#endif

void UItemComboBox::RefreshItems()
{
	TGuardValue<bool> RefreshGuard(bIsRefreshing, true);

	const FName PreviousId = GetSelectedItemId();
	const UInventoryDataSettings& Settings = *GetDefault<UInventoryDataSettings>();

	if (const UItemDatabaseSubsystem* Database = GetDatabase())
	{
		CachedItems = Database->GetItems();
	}
	else
	{
		// UMG designer / no game instance: read the tables directly.
		CachedItems = FItemDatabaseParser::ParseTables(FItemDatabaseParser::LoadConfiguredTables(Settings), Settings);
	}

	const FString& Format = LabelFormatOverride.IsEmpty() ? Settings.ComboBoxLabelFormat : LabelFormatOverride;
	const TArray<FString> Labels = FItemDatabaseParser::BuildUniqueLabels(CachedItems, Format);

	ClearOptions();
	ItemIndexByLabel.Reset();
	LabelById.Reset();

	if (bIncludeEmptyOption)
	{
		AddOption(EmptyOptionLabel);
	}
	for (int32 Index : FItemDatabaseParser::SelectItems(CachedItems, Filter))
	{
		AddOption(Labels[Index]);
		ItemIndexByLabel.Add(Labels[Index], Index);
		LabelById.Add(CachedItems[Index].ItemId, Labels[Index]);
	}

	FName ItemToSelect = PreviousId;
	if (!bHasAppliedInitialItem || IsDesignTime())
	{
		ItemToSelect = InitialItemId;
		bHasAppliedInitialItem = !IsDesignTime();
	}
	if (!SetSelectedItemId(ItemToSelect) && bIncludeEmptyOption)
	{
		SetSelectedOption(EmptyOptionLabel);
	}

	RefreshOptions();
}

bool UItemComboBox::SetSelectedItemId(FName ItemId)
{
	const FString* Label = LabelById.Find(ItemId);
	if (!Label)
	{
		return false;
	}
	SetSelectedOption(*Label);
	return true;
}

FName UItemComboBox::GetItemIdForOption(const FString& Option) const
{
	const int32* Index = ItemIndexByLabel.Find(Option);
	return Index ? CachedItems[*Index].ItemId : NAME_None;
}

bool UItemComboBox::GetItemDescriptorForOption(const FString& Option, FItemDescriptor& OutItem) const
{
	if (const int32* Index = ItemIndexByLabel.Find(Option))
	{
		OutItem = CachedItems[*Index];
		return true;
	}
	return false;
}

TArray<FString> UItemComboBox::GetItemIdOptions() const
{
	TArray<FString> Options = FItemDatabaseParser::GetConfiguredItemIdOptions();
	Options.Insert(FName(NAME_None).ToString(), 0);
	return Options;
}

void UItemComboBox::HandleSelectionChanged(FString SelectedItem, ESelectInfo::Type SelectionType)
{
	if (!bIsRefreshing)
	{
		OnItemSelected.Broadcast(GetItemIdForOption(SelectedItem), SelectionType);
	}
}

void UItemComboBox::HandleDatabaseRebuilt()
{
	RefreshItems();
}

UItemDatabaseSubsystem* UItemComboBox::GetDatabase() const
{
	if (IsDesignTime())
	{
		return nullptr;
	}
	const UWorld* World = GetWorld();
	const UGameInstance* GameInstance = World ? World->GetGameInstance() : nullptr;
	return GameInstance ? GameInstance->GetSubsystem<UItemDatabaseSubsystem>() : nullptr;
}

/**
 * Reads and writes numeric resources (currency, materials, ...) by name through the reflection system.
 * A resource is any numeric property (int8..int64, uint8..uint64, float, double; enums excluded) of the
 * resource source object. Nested struct members are addressed with dots: "Wallet.Gold".
 *
 * Resource source:
 *  - this component (default): make a Blueprint/C++ subclass and add variables like Gold, Wood;
 *  - the owning actor (bUseOwnerAsSource), e.g. a PlayerState with UPROPERTY int32 Gold;
 *  - any object passed to SetResourceSource.
 *
 * Access: if AllowedResources is set, only those names resolve. Otherwise any BlueprintVisible numeric
 * property that is not declared by engine classes is accessible.
 *
 * Integer resources are exact up to 2^53; changes on integer properties are rounded to whole numbers.
 */
UCLASS(ClassGroup = (Inventory), Blueprintable, meta = (BlueprintSpawnableComponent))
class INVENTORYDATA_API UResourceManagerComponent : public UActorComponent

	GENERATED_BODY()

	UResourceManagerComponent();

	UFUNCTION(BlueprintCallable, Category = "Resources")
	void SetResourceSource(UObject* NewSource);

	UFUNCTION(BlueprintPure, Category = "Resources")
	UObject* GetResourceSource() const;

	UFUNCTION(BlueprintPure, Category = "Resources")
	bool HasResource(FName ResourceName) const;

	/** Names of all accessible top-level resources (or of AllowedResources, if set). */
	UFUNCTION(BlueprintPure, Category = "Resources")
	TArray<FName> GetResourceNames() const;

	UFUNCTION(BlueprintPure, Category = "Resources")
	float GetResourceValue(FName ResourceName, bool& bFound) const;

	UFUNCTION(BlueprintCallable, Category = "Resources")
	EResourceOpResult SetResourceValue(FName ResourceName, float NewValue);

	/** Adds Delta (may be negative); the result is clamped by the resource limits. */
	UFUNCTION(BlueprintCallable, Category = "Resources")
	EResourceOpResult AddResource(FName ResourceName, float Delta);

	/** Subtracts Amount only if the whole amount is available. */
	UFUNCTION(BlueprintCallable, Category = "Resources")
	EResourceOpResult TrySpendResource(FName ResourceName, float Amount);

	UFUNCTION(BlueprintPure, Category = "Resources")
	bool CanAfford(FName ResourceName, float Amount) const;

	/** All-or-nothing spend of several resources (crafting, shop prices). Nothing changes unless every cost is affordable. */
	UFUNCTION(BlueprintCallable, Category = "Resources")
	EResourceOpResult TrySpendResources(const TMap<FName, float>& Costs);

	// int64 variants for currencies that exceed float precision (~16.7M).

	UFUNCTION(BlueprintPure, Category = "Resources|Int64", meta = (DisplayName = "Get Resource Value (Int64)"))
	int64 GetResourceValueInt64(FName ResourceName, bool& bFound) const;

	UFUNCTION(BlueprintCallable, Category = "Resources|Int64", meta = (DisplayName = "Set Resource Value (Int64)"))
	EResourceOpResult SetResourceValueInt64(FName ResourceName, int64 NewValue);

	UFUNCTION(BlueprintCallable, Category = "Resources|Int64", meta = (DisplayName = "Add Resource (Int64)"))
	EResourceOpResult AddResourceInt64(FName ResourceName, int64 Delta);

	UFUNCTION(BlueprintCallable, Category = "Resources|Int64", meta = (DisplayName = "Try Spend Resource (Int64)"))
	EResourceOpResult TrySpendResourceInt64(FName ResourceName, int64 Amount);

	// C++ API in double precision; the Blueprint functions above forward here.

	bool TryGetValue(FName ResourceName, double& OutValue) const;
	EResourceOpResult SetValue(FName ResourceName, double NewValue);
	EResourceOpResult ModifyValue(FName ResourceName, double Delta);
	EResourceOpResult TrySpend(FName ResourceName, double Amount);

	/** Broadcast on the machine where the change was made. For replicated sources, use RepNotify on the client side. */
	UPROPERTY(BlueprintAssignable, Category = "Resources")
	FOnResourceValueChanged OnResourceChanged;

protected:
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Resources|Source")
	bool bUseOwnerAsSource = false;

	/** Whitelist of resource names/paths ("Gold", "Wallet.Gold"). Empty = any accessible numeric property. */
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Resources|Access")
	TArray<FName> AllowedResources;

	/** Refuse modifications on non-authority instances, so clients cannot change server-owned values locally. */
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Resources|Access")
	bool bRequireAuthority = true;

	/** Limits for resources not listed in ResourceLimits. By default values cannot go below zero. */
	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Resources|Limits")
	FResourceLimits DefaultLimits;

	UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Resources|Limits")
	TMap<FName, FResourceLimits> ResourceLimits;

private:
	struct FResolvedResource
	{
		FNumericProperty* Property = nullptr;
		void* ValuePtr = nullptr;
	};

	bool Resolve(FName ResourceName, FResolvedResource& Out) const;
	bool IsAccessibleProperty(const FProperty* Property) const;
	bool HasModifyAuthority() const;
	const FResourceLimits& GetLimits(FName ResourceName) const;
	/** Value after spending Amount; false if that would go below the resource floor. */
	bool ComputeSpend(FName ResourceName, const FResolvedResource& Resource, double Amount, double& OutNewValue) const;
	EResourceOpResult Apply(FName ResourceName, const FResolvedResource& Resource, double RequestedValue);

	static double ReadValue(const FResolvedResource& Resource);
	static void WriteValue(const FResolvedResource& Resource, double Value);
	static double ClampToTypeRange(const FNumericProperty* Property, double Value);
	static bool IsUnsigned(const FNumericProperty* Property);

	TWeakObjectPtr<UObject> SourceOverride;
};

{
	/** Largest magnitude at which every integer is exactly representable as double. */
	constexpr double MaxExactInteger = 9007199254740992.0; // 2^53

	bool IsValidNumber(double Value)
	{
		return std::isfinite(Value);
	}
}

UResourceManagerComponent::UResourceManagerComponent()
{
	PrimaryComponentTick.bCanEverTick = false;
}

void UResourceManagerComponent::SetResourceSource(UObject* NewSource)
{
	SourceOverride = NewSource;
}

UObject* UResourceManagerComponent::GetResourceSource() const
{
	if (UObject* Override = SourceOverride.Get())
	{
		return Override;
	}
	if (bUseOwnerAsSource)
	{
		return GetOwner();
	}
	return const_cast<UResourceManagerComponent*>(this);
}

bool UResourceManagerComponent::HasResource(FName ResourceName) const
{
	FResolvedResource Resource;
	return Resolve(ResourceName, Resource);
}

TArray<FName> UResourceManagerComponent::GetResourceNames() const
{
	TArray<FName> Names;
	if (AllowedResources.Num() > 0)
	{
		for (const FName& Name : AllowedResources)
		{
			if (HasResource(Name))
			{
				Names.Add(Name);
			}
		}
		return Names;
	}

	const UObject* Source = GetResourceSource();
	if (!Source)
	{
		return Names;
	}
	const UClass* SourceClass = Source->GetClass();
	for (TFieldIterator<FNumericProperty> It(SourceClass); It; ++It)
	{
		if (!It->IsEnum() && IsAccessibleProperty(*It))
		{
			Names.Add(FName(*SourceClass->GetAuthoredNameForField(*It)));
		}
	}
	return Names;
}

float UResourceManagerComponent::GetResourceValue(FName ResourceName, bool& bFound) const
{
	double Value = 0.0;
	bFound = TryGetValue(ResourceName, Value);
	return static_cast<float>(Value);
}

bool UResourceManagerComponent::TryGetValue(FName ResourceName, double& OutValue) const
{
	FResolvedResource Resource;
	if (!Resolve(ResourceName, Resource))
	{
		return false;
	}
	OutValue = ReadValue(Resource);
	return true;
}

EResourceOpResult UResourceManagerComponent::SetValue(FName ResourceName, double NewValue)
{
	if (!ResourceManagerPrivate::IsValidNumber(NewValue))
	{
		return EResourceOpResult::InvalidAmount;
	}
	if (!HasModifyAuthority())
	{
		return EResourceOpResult::NoAuthority;
	}
	FResolvedResource Resource;
	if (!Resolve(ResourceName, Resource))
	{
		return EResourceOpResult::NotFound;
	}
	return Apply(ResourceName, Resource, NewValue);
}

EResourceOpResult UResourceManagerComponent::ModifyValue(FName ResourceName, double Delta)
{
	if (!ResourceManagerPrivate::IsValidNumber(Delta))
	{
		return EResourceOpResult::InvalidAmount;
	}
	if (!HasModifyAuthority())
	{
		return EResourceOpResult::NoAuthority;
	}
	FResolvedResource Resource;
	if (!Resolve(ResourceName, Resource))
	{
		return EResourceOpResult::NotFound;
	}
	return Apply(ResourceName, Resource, ReadValue(Resource) + Delta);
}

EResourceOpResult UResourceManagerComponent::TrySpend(FName ResourceName, double Amount)
{
	if (!ResourceManagerPrivate::IsValidNumber(Amount) || Amount < 0.0)
	{
		return EResourceOpResult::InvalidAmount;
	}
	if (!HasModifyAuthority())
	{
		return EResourceOpResult::NoAuthority;
	}
	FResolvedResource Resource;
	if (!Resolve(ResourceName, Resource))
	{
		return EResourceOpResult::NotFound;
	}
	double NewValue = 0.0;
	if (!ComputeSpend(ResourceName, Resource, Amount, NewValue))
	{
		return EResourceOpResult::Insufficient;
	}
	return Apply(ResourceName, Resource, NewValue);
}

bool UResourceManagerComponent::CanAfford(FName ResourceName, float Amount) const
{
	FResolvedResource Resource;
	double NewValue = 0.0;
	return Amount >= 0.f && Resolve(ResourceName, Resource) && ComputeSpend(ResourceName, Resource, Amount, NewValue);
}

EResourceOpResult UResourceManagerComponent::TrySpendResources(const TMap<FName, float>& Costs)
{
	if (!HasModifyAuthority())
	{
		return EResourceOpResult::NoAuthority;
	}

	struct FPendingSpend
	{
		FName Name;
		FResolvedResource Resource;
		double NewValue;
	};
	TArray<FPendingSpend> Pending;

	// Validate everything first so a failure leaves all resources untouched.
	for (const TPair<FName, float>& Cost : Costs)
	{
		if (!ResourceManagerPrivate::IsValidNumber(Cost.Value) || Cost.Value < 0.f)
		{
			return EResourceOpResult::InvalidAmount;
		}
		FPendingSpend Spend{Cost.Key, FResolvedResource(), 0.0};
		if (!Resolve(Cost.Key, Spend.Resource))
		{
			return EResourceOpResult::NotFound;
		}
		if (!ComputeSpend(Cost.Key, Spend.Resource, Cost.Value, Spend.NewValue))
		{
			return EResourceOpResult::Insufficient;
		}
		Pending.Add(Spend);
	}

	EResourceOpResult Result = EResourceOpResult::Success;
	for (const FPendingSpend& Spend : Pending)
	{
		if (Apply(Spend.Name, Spend.Resource, Spend.NewValue) == EResourceOpResult::Clamped)
		{
			Result = EResourceOpResult::Clamped;
		}
	}
	return Result;
}

bool UResourceManagerComponent::ComputeSpend(FName ResourceName, const FResolvedResource& Resource, double Amount, double& OutNewValue) const
{
	if (!Resource.Property->IsFloatingPoint())
	{
		Amount = FMath::RoundToDouble(Amount);
	}
	// With bClampMin off the resource may go negative (debt), down to the type range.
	const FResourceLimits& Limits = GetLimits(ResourceName);
	const double Floor = Limits.bClampMin ? Limits.MinValue : ClampToTypeRange(Resource.Property, -TNumericLimits<double>::Max());
	OutNewValue = ReadValue(Resource) - Amount;
	return OutNewValue >= Floor;
}

bool UResourceManagerComponent::Resolve(FName ResourceName, FResolvedResource& Out) const
{
	UObject* Source = GetResourceSource();
	if (!Source || ResourceName.IsNone())
	{
		return false;
	}

	const bool bWhitelisted = AllowedResources.Num() > 0;
	if (bWhitelisted && !AllowedResources.Contains(ResourceName))
	{
		return false;
	}

	TArray<FString> Segments;
	ResourceName.ToString().ParseIntoArray(Segments, TEXT("."));

	const UStruct* Struct = Source->GetClass();
	void* Container = Source;
	for (int32 Index = 0; Index < Segments.Num(); ++Index)
	{
		FProperty* Property = InventoryReflection::FindPropertyByAuthoredName(Struct, FName(*Segments[Index]));
		if (!Property || (!bWhitelisted && !IsAccessibleProperty(Property)))
		{
			return false;
		}
		void* Value = Property->ContainerPtrToValuePtr<void>(Container);

		if (Index == Segments.Num() - 1)
		{
			FNumericProperty* Numeric = CastField<FNumericProperty>(Property);
			if (!Numeric || Numeric->IsEnum())
			{
				return false;
			}
			Out.Property = Numeric;
			Out.ValuePtr = Value;
			return true;
		}

		const FStructProperty* StructProperty = CastField<FStructProperty>(Property);
		if (!StructProperty)
		{
			return false;
		}
		Struct = StructProperty->Struct;
		Container = Value;
	}
	return false;
}

bool UResourceManagerComponent::IsAccessibleProperty(const FProperty* Property) const
{
	if (!Property->HasAnyPropertyFlags(CPF_BlueprintVisible))
	{
		return false;
	}
	// Engine internals and this component's own settings are never resources.
	static const FName BlockedPackages[] = {
		FName(TEXT("/Script/CoreUObject")),
		FName(TEXT("/Script/Engine")),
		FName(TEXT("/Script/InventoryData"))
	};
	const UStruct* Owner = Property->GetOwnerStruct();
	const FName PackageName = Owner ? Owner->GetOutermost()->GetFName() : NAME_None;
	for (const FName& Blocked : BlockedPackages)
	{
		if (PackageName == Blocked)
		{
			return false;
		}
	}
	return true;
}

bool UResourceManagerComponent::HasModifyAuthority() const
{
	const AActor* Owner = GetOwner();
	return !bRequireAuthority || !Owner || Owner->HasAuthority();
}

const FResourceLimits& UResourceManagerComponent::GetLimits(FName ResourceName) const
{
	const FResourceLimits* Limits = ResourceLimits.Find(ResourceName);
	return Limits ? *Limits : DefaultLimits;
}

EResourceOpResult UResourceManagerComponent::Apply(FName ResourceName, const FResolvedResource& Resource, double RequestedValue)
{
	const bool bInteger = !Resource.Property->IsFloatingPoint();
	const double Target = bInteger ? FMath::RoundToDouble(RequestedValue) : RequestedValue;

	const FResourceLimits& Limits = GetLimits(ResourceName);
	double NewValue = Target;
	if (Limits.bClampMin)
	{
		NewValue = FMath::Max(NewValue, static_cast<double>(Limits.MinValue));
	}
	if (Limits.bClampMax)
	{
		NewValue = FMath::Min(NewValue, static_cast<double>(Limits.MaxValue));
	}
	if (bInteger)
	{
		NewValue = FMath::RoundToDouble(NewValue);
	}
	NewValue = ClampToTypeRange(Resource.Property, NewValue);

	const double OldValue = ReadValue(Resource);
	if (NewValue != OldValue)
	{
		WriteValue(Resource, NewValue);
		OnResourceChanged.Broadcast(ResourceName, static_cast<float>(OldValue), static_cast<float>(ReadValue(Resource)));
	}
	return NewValue == Target ? EResourceOpResult::Success : EResourceOpResult::Clamped;
}

double UResourceManagerComponent::ReadValue(const FResolvedResource& Resource)
{
	const FNumericProperty* Property = Resource.Property;
	if (Property->IsFloatingPoint())
	{
		return Property->GetFloatingPointPropertyValue(Resource.ValuePtr);
	}
	if (IsUnsigned(Property))
	{
		return static_cast<double>(Property->GetUnsignedIntPropertyValue(Resource.ValuePtr));
	}
	return static_cast<double>(Property->GetSignedIntPropertyValue(Resource.ValuePtr));
}

void UResourceManagerComponent::WriteValue(const FResolvedResource& Resource, double Value)
{
	FNumericProperty* Property = Resource.Property;
	if (Property->IsFloatingPoint())
	{
		Property->SetFloatingPointPropertyValue(Resource.ValuePtr, Value);
	}
	else if (IsUnsigned(Property))
	{
		Property->SetIntPropertyValue(Resource.ValuePtr, static_cast<uint64>(Value));
	}
	else
	{
		Property->SetIntPropertyValue(Resource.ValuePtr, static_cast<int64>(Value));
	}
}

double UResourceManagerComponent::ClampToTypeRange(const FNumericProperty* Property, double Value)
{
	using ResourceManagerPrivate::MaxExactInteger;

	if (Property->IsA<FFloatProperty>())
	{
		return FMath::Clamp(Value, -static_cast<double>(MAX_FLT), static_cast<double>(MAX_FLT));
	}
	if (Property->IsFloatingPoint())
	{
		return Value;
	}

	double Min = -MaxExactInteger;
	double Max = MaxExactInteger;
	if (Property->IsA<FInt8Property>())        { Min = MIN_int8;  Max = MAX_int8; }
	else if (Property->IsA<FInt16Property>())  { Min = MIN_int16; Max = MAX_int16; }
	else if (Property->IsA<FIntProperty>())    { Min = MIN_int32; Max = MAX_int32; }
	else if (Property->IsA<FByteProperty>())   { Min = 0.0;       Max = MAX_uint8; }
	else if (Property->IsA<FUInt16Property>()) { Min = 0.0;       Max = MAX_uint16; }
	else if (Property->IsA<FUInt32Property>()) { Min = 0.0;       Max = MAX_uint32; }
	else if (Property->IsA<FUInt64Property>()) { Min = 0.0; }
	return FMath::Clamp(Value, Min, Max);
}

bool UResourceManagerComponent::IsUnsigned(const FNumericProperty* Property)
{
	return Property->IsA<FByteProperty>() || Property->IsA<FUInt16Property>()
		|| Property->IsA<FUInt32Property>() || Property->IsA<FUInt64Property>();
}

## 1. Item Database и авто-заполнение ComboBox

### Таблица предметов

Создайте DataTable со структурой строки **`FItemTableRow`**. Можно импортировать `Data/SampleItems.csv`
(поменяйте пути к иконкам на свои). Затем добавьте таблицу в
**Project Settings → Game → Inventory Data → Item Tables**. Таблиц может быть несколько: если ID повторяется,
вторая строка пропускается, а в лог пишется предупреждение.

Структура `FItemTableRow` не обязательна. Парсер читает строки **через рефлексию**, поэтому подойдёт
любая структура строки, как C++, так и Blueprint (User Defined Struct). Имена полей задаются в `FieldMapping`:

| Поле маппинга | Какие типы поддерживаются | Если поля нет |
|---|---|---|
| `IdField` | `FName`, `FString`, целое число | берётся имя строки (Row Name) |
| `NameField` | `FText`, `FString`, `FName` | берётся ID |
| `IconField` | `TSoftObjectPtr`, жёсткая ссылка на объект, строковый путь | иконки нет |
| `RarityField` | `EItemRarity`, любой enum, целое число, строка (`"Epic"`) | `Common` |
| `ColorField` | `FLinearColor`, `FColor` | цвет редкости |
| `ColorOverrideField` | `bool` | цвет из `ColorField` используется всегда |

Поле можно отключить, указав для него `None`.

### Виджет `Item ComboBox`

В UMG Designer он находится в палитре, в категории **Inventory**.

- Заполняется сам, в том числе прямо в дизайнере, так что в превью видны настоящие предметы.
- Во время игры берёт данные из `UItemDatabaseSubsystem` и обновляется после каждого `RebuildDatabase`.
- `Filter` задаёт фильтрацию по редкости и строке поиска, а также сортировку по имени.
- `LabelFormatOverride` задаёт формат подписи с токенами `{Name}`, `{Id}`, `{Rarity}`, например `"{Name} ({Rarity})"`.
  Подписи всегда уникальны: при совпадении к подписи добавляется ` (ID)`.
- `InitialItemId` выбирается из выпадающего списка ID в панели Details (через `meta=(GetOptions)`).
- Событие `OnItemSelected(ItemId, SelectionType)` сразу отдаёт **ID**, а не строку.
- `GetSelectedItemId()` / `SetSelectedItemId()` / `GetItemDescriptorForOption()`.

Чтобы раскрасить строки списка или добавить к ним иконки, привяжите `On Generate Widget Event`
и в обработчике вызовите `GetItemDescriptorForOption(Item)`: результат содержит `Visual.Icon` и `Visual.Color`.

### Обычный `ComboBoxString`

```cpp
UItemDatabaseSubsystem* Db = GetGameInstance()->GetSubsystem<UItemDatabaseSubsystem>();

FItemListFilter Filter;
Filter.AllowedRarities = { EItemRarity::Epic, EItemRarity::Legendary };
Db->PopulateComboBox(MyComboBox, Filter);

// в OnSelectionChanged:
const FName ItemId = Db->GetItemIdFromLabel(SelectedItem);
```

### Выпадающий список ID в своих классах (панель Details)

```cpp
UPROPERTY(EditAnywhere, meta = (GetOptions = "GetItemIdOptions"))
FName RewardItemId;

UFUNCTION()
TArray<FString> GetItemIdOptions() const { return FItemDatabaseParser::GetConfiguredItemIdOptions(); }
```

## 2. Маппинг ID → визуальные свойства

При каждой сборке базы для каждого предмета заполняется `TMap<FName, FItemVisualData>`:

```cpp
USTRUCT(BlueprintType)
struct FItemVisualData
{
    TSoftObjectPtr<UTexture2D> Icon;  // мягкая ссылка: иконка не грузится, пока не понадобится
    FLinearColor Color;               // собственный цвет строки или цвет редкости
    EItemRarity Rarity;
};
```

Цвета редкостей задаются в **Project Settings → Inventory Data → Rarity Colors**.

```cpp
FItemVisualData Visual;
if (Db->GetItemVisual(TEXT("Gem_Sapphire"), Visual))
{
    SlotBorder->SetBrushColor(Visual.Color);
    Db->RequestItemIconAsync(TEXT("Gem_Sapphire"), [this](UTexture2D* Icon)
    {
        if (Icon) { SlotImage->SetBrushFromTexture(Icon); }
    });
}

// Полная строка таблицы, если нужны поля помимо визуала:
if (const FItemTableRow* Row = Db->FindItemRow<FItemTableRow>(TEXT("Potion_Health")))
{
    const int32 MaxStack = Row->MaxStack;
}
```

Другие функции: `FindItem`, `IsValidItem`, `GetAllItemIds`, `FilterItems`, `GetVisualMap`, `GetItemColor`,
`GetRarityColor`, `LoadItemIcon`. Таблицы, загруженные во время игры (DLC, моды), подключаются через
`RegisterItemTable` / `UnregisterItemTable`. В редакторе база пересобирается сама, если во время PIE
изменить таблицу или настройки плагина.

## 3. Менеджер ресурсов (`UResourceManagerComponent`)

Компонент читает и меняет числовые `UPROPERTY` **по имени**, через `FProperty` / `FNumericProperty`.
Поддерживаются `int8…int64`, `uint8…uint64`, `float`, `double`. Enum-свойства исключены. Члены вложенных
структур адресуются через точку: `"Wallet.Gold"`.

### Где хранятся ресурсы

1. **В самом компоненте** (по умолчанию). Создайте Blueprint-наследника `ResourceManagerComponent`
   и добавьте в него переменные `Gold` (Integer64), `Wood` (Integer), `Mana` (Float).
2. **В владельце** (`bUseOwnerAsSource = true`), например в PlayerState:

   ```cpp
   UCLASS()
   class AMyPlayerState : public APlayerState
   {
       GENERATED_BODY()
   public:
       UPROPERTY(Replicated, BlueprintReadOnly, Category = "Resources") int64 Gold = 0;
       UPROPERTY(Replicated, BlueprintReadOnly, Category = "Resources") int32 Wood = 0;
       UPROPERTY(BlueprintReadOnly, Category = "Resources") FMyWallet Wallet; // Wallet.Gems
   };
   ```
3. **В любом объекте**: `SetResourceSource(SomeObject)`.

### API

| Blueprint | C++ (double) | Что делает |
|---|---|---|
| `GetResourceValue` / `…Int64` | `TryGetValue` | читает значение |
| `SetResourceValue` / `…Int64` | `SetValue` | записывает значение с учётом лимитов |
| `AddResource` / `…Int64` | `ModifyValue` | прибавляет (или отнимает) |
| `TrySpendResource` / `…Int64` | `TrySpend` | списывает, только если хватает всей суммы |
| `TrySpendResources(TMap)` | — | списывает несколько ресурсов «всё или ничего» (крафт, магазин) |
| `CanAfford`, `HasResource`, `GetResourceNames` | — | проверки и список доступных ресурсов |

Каждая операция возвращает `EResourceOpResult`: `Success`, `Clamped`, `NotFound`, `Insufficient`,
`InvalidAmount` или `NoAuthority`. После изменения вызывается событие `OnResourceChanged(Name, Old, New)`.

```cpp
UResourceManagerComponent* Res = PlayerState->FindComponentByClass<UResourceManagerComponent>();
Res->AddResourceInt64(TEXT("Gold"), 250);

TMap<FName, float> Recipe = { { TEXT("Wood"), 10.f }, { TEXT("Wallet.Gems"), 2.f } };
if (Res->TrySpendResources(Recipe) == EResourceOpResult::Success)
{
    // выдать предмет
}
```

### Ограничения и безопасность

- **Лимиты.** `DefaultLimits` (по умолчанию значение не может опуститься ниже 0) и `ResourceLimits` для
  отдельных ресурсов (`Min` / `Max`). Значения также зажимаются в диапазон типа: в `int32` переполнения не будет.
  Если отключить `bClampMin`, ресурс может уходить в минус (долг).
- **Доступ.** Если задан `AllowedResources`, работают только перечисленные имена. Если список пуст, доступно
  любое `BlueprintVisible` числовое свойство, кроме объявленных в Engine / CoreUObject и в самом плагине.
  Так через компонент нельзя изменить внутренние поля движка.
- **Сеть.** При `bRequireAuthority = true` клиент получает `NoAuthority`: менять ресурсы можно только на
  сервере, а значения приходят клиентам обычной репликацией свойств источника. `OnResourceChanged`
  вызывается там, где произошло изменение. На клиенте для этого используйте `ReplicatedUsing`.
- **Точность.** Целые значения точны до 2^53. Для больших сумм валюты используйте Int64-варианты функций:
  у float всего около 7 значащих цифр. Изменения целочисленных ресурсов округляются до целого.
