================================================================================
  NOVA PANEL — современный интерфейс на C++20 + Dear ImGui
  Полный исходный код в одном файле + инструкция
================================================================================

Этот файл содержит ВСЕ 25 файлов проекта. Каждый файл начинается строкой

    ######## FILE: путь/к/файлу ########

и заканчивается строкой

    ######## END FILE ########

Всё, что между ними, — точное содержимое файла (без этих двух строк).


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

Создайте папку NovaPanel, внутри неё — папки src, src/app, src/core, src/ui,
src/ui/pages и tests, и разложите файлы строго по путям из строк "FILE:".
Пути в #include (например "core/AppState.h") считаются от папки src, поэтому
менять структуру нельзя.


--------------------------------------------------------------------------------
 2. КАК РАЗЛОЖИТЬ ФАЙЛЫ
--------------------------------------------------------------------------------

Вариант А — вручную: для каждого блока создайте файл по указанному пути и
скопируйте в него текст между строками FILE и END FILE.
Сохраняйте в кодировке UTF-8.

Вариант Б — автоматически (нужен Python 3). Сохраните этот .txt рядом,
создайте файл split.py со следующим содержимым и запустите
"python split.py NovaPanel_full_source.txt":

    import pathlib, sys
    text = pathlib.Path(sys.argv[1]).read_text(encoding="utf-8")
    out, path, buf = pathlib.Path("NovaPanel"), None, []
    for line in text.splitlines(keepends=True):
        if line.startswith("######## FILE: "):
            path = line[len("######## FILE: "):].rsplit(" ########", 1)[0].strip()
            buf = []
        elif line.startswith("######## END FILE ########") and path:
            dst = out / path
            dst.parent.mkdir(parents=True, exist_ok=True)
            dst.write_text("".join(buf), encoding="utf-8")
            print("created", dst)
            path = None
        elif path:
            buf.append(line)

Получится готовая папка NovaPanel со всеми файлами.


--------------------------------------------------------------------------------
 3. ЧТО НУЖНО УСТАНОВИТЬ
--------------------------------------------------------------------------------

  * Компилятор с поддержкой C++20 (нужен <format>):
      - Windows: Visual Studio 2022 (компонент "Разработка классических
        приложений на C++")
      - Linux:   GCC 13+ или Clang 16+
      - macOS:   Xcode 15+ (Apple Clang)
  * CMake 3.20 или новее
  * Git (CMake сам скачивает Dear ImGui v1.91.9 и, если нужно, GLFW 3.4)
  * Интернет при первой сборке

  Linux (Ubuntu/Debian) — системные пакеты:
      sudo apt install build-essential cmake git libgl-dev libglfw3-dev
  (если libglfw3-dev не ставить, GLFW скачается и соберётся сам; тогда нужны
   ещё пакеты X11: libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev
   libxi-dev)

  Windows и macOS — ничего дополнительно ставить не нужно.


--------------------------------------------------------------------------------
 4. СБОРКА И ЗАПУСК
--------------------------------------------------------------------------------

  Откройте терминал в папке NovaPanel и выполните:

      cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
      cmake --build build --config Release -j

  Запуск:
      Linux / macOS:  ./build/nova_panel
      Windows:        build\Release\nova_panel.exe

  Тесты (без окна и без видеокарты):
      ctest --test-dir build -C Release --output-on-failure

  Visual Studio: можно просто открыть папку NovaPanel через
  "Файл -> Открыть -> Папка" — CMake-проект подхватится автоматически.

  Шрифт: программа ищет Segoe UI / Arial / Noto Sans / DejaVu Sans. Для лучшего
  вида положите Inter-Regular.ttf и Inter-SemiBold.ttf в
  NovaPanel/assets/fonts/ и запускайте программу из папки NovaPanel.


--------------------------------------------------------------------------------
 5. КАК УСТРОЕН КОД (кратко)
--------------------------------------------------------------------------------

  Каждый кадр:
     Controller::tick(dt)  ->  MainWindow::draw(state, actions)  ->  Controller::process(actions)
        симуляция              только чтение + намерения              применение и проверка

  * core/ ничего не знает об ImGui. AppState — просто данные.
  * Страницы (ui/pages) получают const AppState& и не могут его менять.
    Они редактируют копию настроек ("черновик") и отправляют действие,
    например action::UpdateCombat{draft}.
  * Controller проверяет значения (std::clamp) и применяет правила игры:
    квестовый предмет нельзя выбросить, в неоткрытую локацию нельзя
    переместиться, зелье лечит игрока и т.д.
  * Стиль (тёмная тема, скругления, цвета) задаётся в ui/Theme.cpp,
    функция theme::apply().

  Как добавить новую вкладку:
    1) создайте класс-наследник ui::Page (см. ui/pages/Page.h);
    2) добавьте значение в enum PageId (ui/MainWindow.h);
    3) добавьте std::make_unique<ВашаСтраница>() в конструктор MainWindow
       и .cpp-файл в список nova_ui в CMakeLists.txt.

// Platform layer: GLFW window + OpenGL 3 renderer for Dear ImGui.
// Everything application-specific lives in app::Application.

#include "app/Application.h"
#include "ui/Theme.h"

#include <imgui.h>
#include <imgui_impl_glfw.h>
#include <imgui_impl_opengl3.h>

#include <GLFW/glfw3.h>

#include <chrono>
#include <cstdio>
#include <thread>

namespace {

void glfwErrorCallback(int error, const char* description) {
    std::fprintf(stderr, "GLFW error %d: %s\n", error, description);
}

}  // namespace

int main() {
    glfwSetErrorCallback(glfwErrorCallback);
    if (!glfwInit()) return 1;

#if defined(__APPLE__)
    const char* glslVersion = "#version 150";
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 2);
    glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
    glfwWindowHint(GLFW_OPENGL_FORWARD_COMPAT, GL_TRUE);
#else
    const char* glslVersion = "#version 130";
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 0);
#endif

    GLFWwindow* window = glfwCreateWindow(1280, 800, "Nova Panel", nullptr, nullptr);
    if (!window) {
        glfwTerminate();
        return 1;
    }
    glfwMakeContextCurrent(window);
    glfwSwapInterval(1);

    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    ImGuiIO& io = ImGui::GetIO();
    io.ConfigFlags |= ImGuiConfigFlags_NavEnableKeyboard;
    io.IniFilename = nullptr;

    ui::theme::loadFonts(io);
    ImGui_ImplGlfw_InitForOpenGL(window, true);
    ImGui_ImplOpenGL3_Init(glslVersion);

    {
        app::Application application;
        bool vsync = true;

        while (!glfwWindowShouldClose(window)) {
            const auto frameStart = std::chrono::steady_clock::now();
            glfwPollEvents();
            if (glfwGetWindowAttrib(window, GLFW_ICONIFIED)) {
                ImGui_ImplGlfw_Sleep(10);
                continue;
            }

            ImGui_ImplOpenGL3_NewFrame();
            ImGui_ImplGlfw_NewFrame();
            ImGui::NewFrame();
            application.frame(io.DeltaTime);
            ImGui::Render();

            int width = 0, height = 0;
            glfwGetFramebufferSize(window, &width, &height);
            glViewport(0, 0, width, height);
            const ImVec4 bg = ui::theme::palette().background;
            glClearColor(bg.x, bg.y, bg.z, 1.0f);
            glClear(GL_COLOR_BUFFER_BIT);
            ImGui_ImplOpenGL3_RenderDrawData(ImGui::GetDrawData());
            glfwSwapBuffers(window);

            // Apply platform-level settings coming from the state.
            const core::GeneralSettings& general = application.state().settings.general;
            if (general.vsync != vsync) {
                vsync = general.vsync;
                glfwSwapInterval(vsync ? 1 : 0);
            }
            const int fpsLimit = core::kFpsLimitValues[static_cast<std::size_t>(general.fpsLimit)];
            if (!vsync && fpsLimit > 0)
                std::this_thread::sleep_until(frameStart + std::chrono::microseconds(1'000'000 / fpsLimit));
        }
    }

    ImGui_ImplOpenGL3_Shutdown();
    ImGui_ImplGlfw_Shutdown();
    ImGui::DestroyContext();
    glfwDestroyWindow(window);
    glfwTerminate();
    return 0;
}

#pragma once

// Wires model, logic and view together and defines the order of a frame:
//   1. Controller::tick      - simulation
//   2. MainWindow::draw      - read-only rendering, user intent -> ActionQueue
//   3. Controller::process   - actions are applied to the state

#include "core/Actions.h"
#include "core/AppState.h"
#include "core/Controller.h"
#include "ui/MainWindow.h"

namespace app {

class Application {
public:
    Application();

    // Call between ImGui::NewFrame() and ImGui::Render().
    void frame(float dt);

    [[nodiscard]] const core::AppState& state() const { return m_state; }
    [[nodiscard]] ui::MainWindow& window() { return m_window; }
    [[nodiscard]] core::Controller& controller() { return m_controller; }

private:
    core::AppState m_state;
    core::ActionQueue m_actions;
    core::Controller m_controller;
    ui::MainWindow m_window;
};

}  // namespace app

#include "app/Application.h"

#include "ui/Theme.h"

namespace app {

Application::Application() : m_state(core::makeDemoState()), m_controller(m_state) {
    m_controller.onAppearanceChanged = [](const core::AppearanceSettings& appearance) { ui::theme::apply(appearance); };
    ui::theme::apply(m_state.settings.appearance);
}

void Application::frame(float dt) {
    m_controller.tick(dt);
    m_window.draw(m_state, m_actions);
    m_controller.process(m_actions);
}

float totalWeight(const InventoryState& inventory) {
    return std::accumulate(inventory.items.begin(), inventory.items.end(), 0.0f,
                           [](float sum, const Item& item) { return sum + item.weight * static_cast<float>(item.quantity); });
}

float distance(const Vec3& a, const Vec3& b) {
    const float dx = a.x - b.x, dy = a.y - b.y, dz = a.z - b.z;
    return std::sqrt(dx * dx + dy * dy + dz * dz);
}

using Action = std::variant<
    action::UpdateCombat,
    action::UpdatePlayer,
    action::UpdateWorld,
    action::UpdateInventoryPrefs,
    action::UpdateAppearance,
    action::UpdateGeneral,
    action::HealPlayer,

// Write-only interface given to views. Keeps the UI unaware of who handles actions.
class ActionSink {
public:
    virtual ~ActionSink() = default;
    virtual void dispatch(Action action) = 0;
};

// Actions are queued during the frame and applied after the UI has been drawn,
// so the state stays consistent for the whole frame.
class ActionQueue final : public ActionSink {
public:
    void dispatch(Action action) override { m_pending.push_back(std::move(action)); }

    [[nodiscard]] std::vector<Action> drain() { return std::exchange(m_pending, {}); }
    [[nodiscard]] bool empty() const { return m_pending.empty(); }

private:
    std::vector<Action> m_pending;
};

template <class T>
constexpr T clampIndex(T value, std::size_t count) {
    return std::clamp<T>(value, 0, static_cast<T>(count) - 1);
}

constexpr auto idx(auto e) { return static_cast<std::size_t>(e); }

}  // namespace

Controller::Controller(AppState& state) : m_state(state) { sortInventory(); }

void Controller::handle(const Action& action) {
    std::visit([this](const auto& a) { apply(a); }, action);
}

void Controller::process(ActionQueue& queue) {
    for (const Action& action : queue.drain()) handle(action);
}

void Controller::tick(float dt) {
    m_state.clock += dt;

    auto& world = m_state.explorer.world;
    if (!world.freezeTime) {
        world.timeOfDay = std::fmod(world.timeOfDay + dt * world.timeScale / 60.0f, 24.0f);
    }

    auto& p = m_state.player;
    if (p.healthRegen && p.health < p.maxHealth) p.health = std::min(p.maxHealth, p.health + 1.5f * dt);
    if (p.infiniteStamina) p.stamina = p.maxStamina;
    else if (p.stamina < p.maxStamina) p.stamina = std::min(p.maxStamina, p.stamina + 8.0f * dt);
}

void Controller::apply(const action::UseItem& a) {
    auto& items = m_state.inventory.items;
    const auto it = std::ranges::find(items, a.itemId, &Item::id);
    if (it == items.end()) return;

    switch (it->category) {
        case ItemCategory::Weapon:
        case ItemCategory::Armor:
            // Only one item per slot can be equipped.
            if (!it->equipped)
                for (Item& other : items)
                    if (other.category == it->category) other.equipped = false;
            it->equipped = !it->equipped;
            log(LogLevel::Info, std::format("{} {}", it->equipped ? "Equipped" : "Unequipped", it->name));
            break;

        case ItemCategory::Consumable: {
            const float heal = 15.0f * static_cast<float>(idx(it->rarity) + 1);
            auto& p = m_state.player;
            p.health = std::min(p.maxHealth, p.health + heal);
            log(LogLevel::Success, std::format("Used {} (+{:.0f} HP)", it->name, heal));
            if (--it->quantity <= 0) items.erase(it);
            break;
        }

        default:
            log(LogLevel::Warning, std::format("{} can't be used directly", it->name));
            break;
    }
}

void Controller::apply(const action::DropItem& a) {
    auto& items = m_state.inventory.items;
    const auto it = std::ranges::find(items, a.itemId, &Item::id);
    if (it == items.end()) return;

    if (it->category == ItemCategory::Quest) {
        log(LogLevel::Error, std::format("Quest item '{}' can't be dropped", it->name));
        return;
    }
    log(LogLevel::Info, std::format("Dropped {} x{}", it->name, it->quantity));
    items.erase(it);
}

void Controller::apply(const action::SpawnRandomItem&) {
    static constexpr std::array kNames{
        "Rusty Dagger", "Oak Shield", "Moonpetal Herb", "Silver Ingot", "Phoenix Feather",
        "Warden's Helm", "Bread Loaf", "Runed Gemstone", "Venom Flask", "Spellbound Staff",
    };
    static constexpr std::array kCategories{
        ItemCategory::Weapon, ItemCategory::Armor, ItemCategory::Consumable, ItemCategory::Material, ItemCategory::Material,
        ItemCategory::Armor, ItemCategory::Consumable, ItemCategory::Material, ItemCategory::Consumable, ItemCategory::Weapon,
    };
    static_assert(kNames.size() == kCategories.size());

    auto& inv = m_state.inventory;
    const std::size_t pick = std::uniform_int_distribution<std::size_t>(0, kNames.size() - 1)(m_rng);
    // Skewed towards common items: 40/28/18/10/4 %.
    const auto rarity = static_cast<Rarity>(std::discrete_distribution<int>({40, 28, 18, 10, 4})(m_rng));

    if (static_cast<int>(rarity) < inv.prefs.lootFilter) {
        log(LogLevel::Info, std::format("Skipped {} ({}) - below loot filter", kNames[pick], kRarityNames[idx(rarity)]));
        return;
    }

    const float weight = std::uniform_real_distribution<float>(0.2f, 5.0f)(m_rng);
    if (totalWeight(inv) + weight > inv.maxWeight) {
        log(LogLevel::Error, "Inventory is too heavy to pick up more items");
        return;
    }

    inv.items.push_back(Item{
        .id = inv.nextItemId++,
        .name = kNames[pick],
        .category = kCategories[pick],
        .rarity = rarity,
        .quantity = 1,
        .weight = weight,
    });
    log(LogLevel::Success, std::format("Picked up {} ({})", kNames[pick], kRarityNames[idx(rarity)]));
    if (inv.prefs.autoSortOnPickup) sortInventory();
}

void Controller::apply(const action::SortInventory&) {
    sortInventory();
    log(LogLevel::Info, std::format("Inventory sorted by {}", kSortModes[idx(m_state.inventory.prefs.sortMode)]));
}

void Controller::sortInventory() {
    const auto& prefs = m_state.inventory.prefs;
    auto less = [mode = prefs.sortMode](const Item& a, const Item& b) {
        switch (mode) {
            case 0: return a.name < b.name;
            case 1: return a.rarity < b.rarity;
            case 2: return a.category < b.category;
            default: return a.weight * a.quantity < b.weight * b.quantity;
        }
    };
    auto& items = m_state.inventory.items;
    if (prefs.sortDescending)
        std::ranges::stable_sort(items, [&](const Item& a, const Item& b) { return less(b, a); });
    else
        std::ranges::stable_sort(items, less);
}

// ------------------------------------------------------------- Explorer ----

void Controller::apply(const action::TeleportTo& a) {
    auto& ex = m_state.explorer;
    if (a.locationIndex < 0 || a.locationIndex >= static_cast<int>(ex.locations.size())) return;

    const Location& target = ex.locations[static_cast<std::size_t>(a.locationIndex)];
    if (!target.discovered) {
        log(LogLevel::Error, std::format("{} is not discovered yet", target.name));
        return;
    }
    if (a.locationIndex == ex.currentLocation) return;

    ex.currentLocation = a.locationIndex;
    log(LogLevel::Success, std::format("Travelled to {}", target.name));
}

void Controller::apply(const action::RevealAllLocations&) {
    auto& locations = m_state.explorer.locations;
    const auto hidden = std::ranges::count(locations, false, &Location::discovered);
    for (Location& l : locations) l.discovered = true;
    log(LogLevel::Success, std::format("Revealed {} location(s)", hidden));
}

// ------------------------------------------------------------------ Log ----

void Controller::apply(const action::ClearLog&) { m_state.log.clear(); }

void Controller::log(LogLevel level, std::string message) {
    m_state.log.push_back({m_state.clock, level, std::move(message)});
    while (m_state.log.size() > kMaxLogEntries) m_state.log.pop_front();
}

ImVec4 lerp(const ImVec4& a, const ImVec4& b, float t) {
    return {a.x + (b.x - a.x) * t, a.y + (b.y - a.y) * t, a.z + (b.z - a.z) * t, a.w + (b.w - a.w) * t};
}

ImVec4 rarityColor(core::Rarity rarity) {

        case core::Rarity::Common: return {0.70f, 0.72f, 0.78f, 1.0f};

void loadFonts(ImGuiIO& io) {
    const ImWchar* ranges = io.Fonts->GetGlyphRangesCyrillic();  // Latin + Cyrillic

    for (const FontPair& pair : kFontCandidates) {
        if (!exists(pair.regular)) continue;
        const char* bold = exists(pair.bold) ? pair.bold.data() : pair.regular.data();

        g_fonts.body = io.Fonts->AddFontFromFileTTF(pair.regular.data(), 16.0f, nullptr, ranges);
        g_fonts.strong = io.Fonts->AddFontFromFileTTF(bold, 16.0f, nullptr, ranges);
        g_fonts.heading = io.Fonts->AddFontFromFileTTF(bold, 24.0f, nullptr, ranges);
        g_fonts.small = io.Fonts->AddFontFromFileTTF(pair.regular.data(), 13.0f, nullptr, ranges);
        if (g_fonts.body && g_fonts.strong && g_fonts.heading && g_fonts.small) {
            io.FontDefault = g_fonts.body;
            return;
        }
        io.Fonts->Clear();
    }

    // Fallback: the built-in ProggyClean bitmap font at a few sizes.
    auto makeDefault = [&io](float size) {
        ImFontConfig cfg;
        cfg.SizePixels = size;
        return io.Fonts->AddFontDefault(&cfg);
    };
    g_fonts.body = makeDefault(13.0f);
    g_fonts.strong = g_fonts.body;
    g_fonts.heading = makeDefault(26.0f);
    g_fonts.small = g_fonts.body;
    io.FontDefault = g_fonts.body;
}

void apply(const core::AppearanceSettings& appearance) {
    g_animations = appearance.animations;

    Palette& p = g_palette;
    p.accent = accentPreset(appearance.accent);
    p.accentHover = lerp(p.accent, ImVec4{1, 1, 1, 1}, 0.12f);
    p.accentActive = lerp(p.accent, ImVec4{0, 0, 0, 1}, 0.15f);
    p.accentSoft = withAlpha(p.accent, 0.16f);

    ImGuiStyle& style = ImGui::GetStyle();
    style = ImGuiStyle{};  // start from a clean slate so ScaleAllSizes() doesn't accumulate

    // ---- Geometry -----------------------------------------------------------
    const float r = appearance.rounding;
    style.WindowPadding = {18.0f, 16.0f};
    style.FramePadding = {10.0f, 6.0f};

#include "ui/Icons.h"

#include <algorithm>

namespace ui {

namespace {

constexpr float kPi = std::numbers::pi_v<float>;

ImVec2 operator+(ImVec2 a, ImVec2 b) { return {a.x + b.x, a.y + b.y}; }

ImVec2 polar(ImVec2 c, float radius, float angle) {
    return {c.x + std::cos(angle) * radius, c.y + std::sin(angle) * radius};
}

void drawLogo(ImDrawList* dl, ImVec2 c, float s, ImU32 col) {
    // Faceted diamond.
    const float r = s * 0.5f;
    const ImVec2 top = c + ImVec2{0, -r}, right = c + ImVec2{r * 0.8f, 0};
    const ImVec2 bottom = c + ImVec2{0, r}, left = c + ImVec2{-r * 0.8f, 0};
    dl->AddQuadFilled(top, right, bottom, left, col);
    const ImU32 facet = IM_COL32(255, 255, 255, 70);
    dl->AddTriangleFilled(top, right, c, facet);
    dl->AddTriangleFilled(left, c, bottom, IM_COL32(0, 0, 0, 50));
}

void drawCrosshair(ImDrawList* dl, ImVec2 c, float s, ImU32 col, float t) {
    const float r = s * 0.36f;
    dl->AddCircle(c, r, col, 32, t);
    const float in = r * 0.45f, out = s * 0.5f;
    for (int i = 0; i < 4; ++i) {
        const float a = static_cast<float>(i) * kPi * 0.5f;
        dl->AddLine(polar(c, in, a), polar(c, out, a), col, t);
    }
    dl->AddCircleFilled(c, t * 1.1f, col);
}

void drawPlayer(ImDrawList* dl, ImVec2 c, float s, ImU32 col, float t) {
    dl->AddCircle(c + ImVec2{0, -s * 0.18f}, s * 0.2f, col, 24, t);
    // Shoulders: upper half of an ellipse-ish arc.
    dl->PathArcTo(c + ImVec2{0, s * 0.48f}, s * 0.36f, kPi * 1.08f, kPi * 1.92f, 24);
    dl->PathStroke(col, ImDrawFlags_None, t);
}

void drawInventory(ImDrawList* dl, ImVec2 c, float s, ImU32 col, float t) {
    // Backpack: body, flap and handle.
    const ImVec2 min = c + ImVec2{-s * 0.34f, -s * 0.22f};
    const ImVec2 max = c + ImVec2{s * 0.34f, s * 0.42f};
    dl->AddRect(min, max, col, s * 0.12f, ImDrawFlags_None, t);
    dl->AddLine({min.x, c.y + s * 0.06f}, {max.x, c.y + s * 0.06f}, col, t);
    dl->AddRectFilled(c + ImVec2{-s * 0.07f, s * 0.02f}, c + ImVec2{s * 0.07f, s * 0.14f}, col, 1.0f);
    dl->PathArcTo(c + ImVec2{0, -s * 0.22f}, s * 0.15f, kPi, kPi * 2.0f, 12);
    dl->PathStroke(col, ImDrawFlags_None, t);
}

void drawCompass(ImDrawList* dl, ImVec2 c, float s, ImU32 col, float t) {
    const float r = s * 0.44f;
    dl->AddCircle(c, r, col, 32, t);
    const float a = -kPi * 0.25f;  // needle points north-east
    const ImVec2 tip = polar(c, r * 0.7f, a), tail = polar(c, r * 0.7f, a + kPi);
    const ImVec2 l = polar(c, r * 0.22f, a - kPi * 0.5f), rr = polar(c, r * 0.22f, a + kPi * 0.5f);
    dl->AddTriangleFilled(tip, rr, l, col);
    dl->AddTriangle(tail, l, rr, col, t * 0.8f);
}

void drawGear(ImDrawList* dl, ImVec2 c, float s, ImU32 col, float t) {
    constexpr int kTeeth = 8;
    const float outer = s * 0.46f, inner = s * 0.34f;
    const float step = 2.0f * kPi / kTeeth;

    std::array<ImVec2, kTeeth * 4> pts{};
    for (int i = 0; i < kTeeth; ++i) {
        const float a = static_cast<float>(i) * step;
        pts[i * 4 + 0] = polar(c, inner, a - step * 0.30f);
        pts[i * 4 + 1] = polar(c, outer, a - step * 0.18f);
        pts[i * 4 + 2] = polar(c, outer, a + step * 0.18f);
        pts[i * 4 + 3] = polar(c, inner, a + step * 0.30f);
    }
    dl->AddPolyline(pts.data(), static_cast<int>(pts.size()), col, ImDrawFlags_Closed, t);
    dl->AddCircle(c, s * 0.14f, col, 20, t);
}

}  // namespace

void drawIcon(ImDrawList* dl, Icon icon, ImVec2 center, float size, ImU32 color) {
    const float thickness = std::max(1.5f, size * 0.085f);
    switch (icon) {
        case Icon::Logo: drawLogo(dl, center, size, color); break;
        case Icon::Combat: drawCrosshair(dl, center, size, color, thickness); break;
        case Icon::Player: drawPlayer(dl, center, size, color, thickness); break;
        case Icon::Inventory: drawInventory(dl, center, size, color, thickness); break;
        case Icon::Explorer: drawCompass(dl, center, size, color, thickness); break;
        case Icon::Settings: drawGear(dl, center, size, color, thickness); break;
    }
}

ImU32 u32(const ImVec4& c) { return ImGui::ColorConvertFloat4ToU32(c); }

float scale() { return ImGui::GetIO().FontGlobalScale; }

// Starts a "label | control" row and sets the width for the control that follows.
void beginRow(const char* label) {
    const float x0 = ImGui::GetCursorScreenPos().x;
    const float avail = ImGui::GetContentRegionAvail().x;
    const float labelWidth = std::floor(avail * 0.42f);

    ImGui::AlignTextToFramePadding();
    ImGui::TextUnformatted(label);
    ImGui::SameLine();
    ImGui::SetCursorScreenPos({x0 + labelWidth, ImGui::GetCursorScreenPos().y});
    ImGui::SetNextItemWidth(avail - labelWidth);
}

void hintUnderneath(const char* hint, float indent) {
    ImGui::SetCursorPosY(ImGui::GetCursorPosY() - ImGui::GetStyle().ItemSpacing.y * 0.6f);
    if (indent > 0) ImGui::Indent(indent);
    caption(hint);
    if (indent > 0) ImGui::Unindent(indent);
}

}  // namespace

float animate(ImGuiID id, float target, float speed) {
    float* value = ImGui::GetStateStorage()->GetFloatRef(id, target);
    if (!theme::animationsEnabled()) return *value = target;

    const float k = 1.0f - std::exp(-speed * ImGui::GetIO().DeltaTime);
    *value += (target - *value) * k;
    if (std::abs(target - *value) < 1e-3f) *value = target;
    return *value;
}

bool sidebarButton(const char* id, Icon icon, bool selected, const char* tooltip, float sidebarLeftX) {
    const auto& pal = theme::palette();
    const float size = 46.0f * scale();

    ImGui::PushID(id);
    const ImVec2 pos = ImGui::GetCursorScreenPos();
    const bool clicked = ImGui::InvisibleButton("##btn", {size, size});
    const bool hovered = ImGui::IsItemHovered();

    const float sel = animate(ImGui::GetID("sel"), selected ? 1.0f : 0.0f);
    const float hov = animate(ImGui::GetID("hov"), hovered ? 1.0f : 0.0f);

    ImDrawList* dl = ImGui::GetWindowDrawList();
    const ImVec2 max = pos + ImVec2{size, size};
    const float rounding = ImGui::GetStyle().FrameRounding + 4.0f * scale();

    if (hov > 0.01f) dl->AddRectFilled(pos, max, u32(theme::withAlpha(pal.surfaceTop, 0.6f * hov)), rounding);
    if (sel > 0.01f) dl->AddRectFilled(pos, max, u32(theme::withAlpha(pal.accent, 0.18f * sel)), rounding);

    // Active indicator glued to the left edge of the sidebar.
    if (sel > 0.01f) {
        const float h = size * 0.5f * sel;
        const float cy = pos.y + size * 0.5f;
        dl->AddRectFilled({sidebarLeftX, cy - h * 0.5f}, {sidebarLeftX + 3.0f * scale(), cy + h * 0.5f},
                          u32(pal.accent), 2.0f, ImDrawFlags_RoundCornersRight);
    }

    const ImVec4 iconColor = theme::lerp(theme::lerp(pal.textMuted, pal.text, hov), pal.accent, sel);
    drawIcon(dl, icon, pos + ImVec2{size, size} * 0.5f, size * 0.44f, u32(iconColor));

    if (tooltip && ImGui::IsItemHovered(ImGuiHoveredFlags_DelayShort)) ImGui::SetTooltip("%s", tooltip);
    ImGui::PopID();
    return clicked;
}

bool pillTabs(const char* id, std::span<const char* const> labels, int& current) {
    if (labels.empty()) return false;
    const auto& pal = theme::palette();
    const float s = scale();
    const ImVec2 pad{16.0f * s, 7.0f * s};
    const float inset = 4.0f * s;
    const float pillH = ImGui::GetTextLineHeight() + pad.y * 2.0f;

    ImGui::PushID(id);
    current = std::clamp(current, 0, static_cast<int>(labels.size()) - 1);

    // Measure.
    float totalW = inset;
    float targetX = 0, targetW = 0;
    for (int i = 0; i < static_cast<int>(labels.size()); ++i) {
        const float w = ImGui::CalcTextSize(labels[i]).x + pad.x * 2.0f;
        if (i == current) targetX = totalW, targetW = w;
        totalW += w;
    }
    totalW += inset;

    const ImVec2 origin = ImGui::GetCursorScreenPos();
    const ImVec2 size{totalW, pillH + inset * 2.0f};
    ImDrawList* dl = ImGui::GetWindowDrawList();
    dl->AddRectFilled(origin, origin + size, u32(pal.surface), size.y * 0.5f);
    dl->AddRect(origin, origin + size, u32(pal.border), size.y * 0.5f);

    // Sliding highlight.
    const float hx = animate(ImGui::GetID("x"), targetX, 18.0f);
    const float hw = animate(ImGui::GetID("w"), targetW, 18.0f);
    const ImVec2 hMin = origin + ImVec2{hx, inset};
    dl->AddRectFilled(hMin, hMin + ImVec2{hw, pillH}, u32(pal.accent), pillH * 0.5f);

    bool changed = false;
    float x = inset;
    for (int i = 0; i < static_cast<int>(labels.size()); ++i) {
        const ImVec2 textSize = ImGui::CalcTextSize(labels[i]);
        const float w = textSize.x + pad.x * 2.0f;
        const ImVec2 pMin = origin + ImVec2{x, inset};

        ImGui::SetCursorScreenPos(pMin);
        ImGui::PushID(i);
        if (ImGui::InvisibleButton("##pill", {w, pillH}) && current != i) {
            current = i;
            changed = true;
        }
        const bool hovered = ImGui::IsItemHovered();
        ImGui::PopID();

        const ImVec4 col = i == current ? ImVec4{1, 1, 1, 1} : hovered ? pal.text : pal.textMuted;
        dl->AddText(pMin + ImVec2{pad.x, pad.y}, u32(col), labels[i]);
        x += w;
    }

    ImGui::SetCursorScreenPos(origin);
    ImGui::Dummy(size);
    ImGui::PopID();
    return changed;
}

bool toggle(const char* label, bool* value, const char* hint) {
    const auto& pal = theme::palette();
    const ImGuiStyle& style = ImGui::GetStyle();

    ImGui::PushID(label);
    const ImVec2 pos = ImGui::GetCursorScreenPos();
    const float width = ImGui::GetContentRegionAvail().x;
    const float frameH = ImGui::GetFrameHeight();
    const float lineH = ImGui::GetTextLineHeight();

    float hintH = 0.0f;
    if (hint) {
        ImGui::PushFont(theme::fonts().small);
        hintH = ImGui::GetTextLineHeight() + 2.0f * scale();
        ImGui::PopFont();
    }
    const float rowH = std::max(frameH, lineH + hintH);

    const bool clicked = ImGui::InvisibleButton("##toggle", {width, rowH});
    if (clicked) *value = !*value;
    const bool hovered = ImGui::IsItemHovered();

    ImDrawList* dl = ImGui::GetWindowDrawList();
    const float textY = pos.y + (rowH - lineH - hintH) * 0.5f;
    dl->AddText({pos.x, textY}, u32(pal.text), label);
    if (hint) {
        ImGui::PushFont(theme::fonts().small);
        dl->AddText({pos.x, textY + lineH + 2.0f * scale()}, u32(pal.textMuted), hint);
        ImGui::PopFont();
    }

    // Switch.
    const float h = frameH * 0.78f;
    const float w = h * 1.8f;
    const ImVec2 sMin{pos.x + width - w - style.FramePadding.x * 0.25f, pos.y + (rowH - h) * 0.5f};
    const float t = animate(ImGui::GetID("knob"), *value ? 1.0f : 0.0f, 16.0f);

    ImVec4 track = theme::lerp(pal.surfaceTop, pal.accent, t);
    if (hovered) track = theme::lerp(track, ImVec4{1, 1, 1, 1}, 0.08f);
    dl->AddRectFilled(sMin, sMin + ImVec2{w, h}, u32(track), h * 0.5f);

    const float r = h * 0.5f - 3.0f * scale();
    const ImVec2 knob{sMin.x + h * 0.5f + (w - h) * t, sMin.y + h * 0.5f};
    dl->AddCircleFilled(knob + ImVec2{0, 1}, r, IM_COL32(0, 0, 0, 60));
    dl->AddCircleFilled(knob, r, IM_COL32(255, 255, 255, 255));

    ImGui::PopID();
    return clicked;
}

bool checkbox(const char* label, bool* value, const char* hint) {
    const auto& pal = theme::palette();
    const bool on = *value;
    if (on) {
        ImGui::PushStyleColor(ImGuiCol_FrameBg, pal.accent);
        ImGui::PushStyleColor(ImGuiCol_FrameBgHovered, pal.accentHover);
        ImGui::PushStyleColor(ImGuiCol_FrameBgActive, pal.accentActive);
    }
    const bool changed = ImGui::Checkbox(label, value);
    if (on) ImGui::PopStyleColor(3);

    if (hint) hintUnderneath(hint, ImGui::GetFrameHeight() + ImGui::GetStyle().ItemInnerSpacing.x);
    return changed;
}

bool button(const char* label, ButtonKind kind, ImVec2 size) {
    const auto& pal = theme::palette();
    int colors = 0;
    switch (kind) {
        case ButtonKind::Primary:
            ImGui::PushStyleColor(ImGuiCol_Button, pal.accent);
            ImGui::PushStyleColor(ImGuiCol_ButtonHovered, pal.accentHover);
            ImGui::PushStyleColor(ImGuiCol_ButtonActive, pal.accentActive);
            ImGui::PushStyleColor(ImGuiCol_Text, ImVec4{1, 1, 1, 1});
            colors = 4;
            break;
        case ButtonKind::Danger:
            ImGui::PushStyleColor(ImGuiCol_Button, theme::withAlpha(pal.danger, 0.14f));
            ImGui::PushStyleColor(ImGuiCol_ButtonHovered, theme::withAlpha(pal.danger, 0.24f));
            ImGui::PushStyleColor(ImGuiCol_ButtonActive, theme::withAlpha(pal.danger, 0.34f));
            ImGui::PushStyleColor(ImGuiCol_Text, pal.danger);
            colors = 4;
            break;
        case ButtonKind::Secondary: break;
    }
    const bool pressed = ImGui::Button(label, size);
    ImGui::PopStyleColor(colors);
    return pressed;
}

void statBar(const char* label, float value, float max, ImVec4 color) {
    const auto& pal = theme::palette();
    const float s = scale();
    const float width = ImGui::GetContentRegionAvail().x;

    char valueText[32];
    std::snprintf(valueText, sizeof valueText, "%.0f / %.0f", value, max);

    ImGui::PushStyleColor(ImGuiCol_Text, pal.textMuted);
    ImGui::TextUnformatted(label);
    ImGui::PopStyleColor();
    ImGui::SameLine(0, 0);
    ImGui::SetCursorPosX(ImGui::GetCursorPosX() + width - ImGui::CalcTextSize(label).x - ImGui::CalcTextSize(valueText).x);
    ImGui::TextUnformatted(valueText);

    const float fraction = max > 0 ? std::clamp(value / max, 0.0f, 1.0f) : 0.0f;
    const float shown = animate(ImGui::GetID(label), fraction, 10.0f);

    const ImVec2 pos = ImGui::GetCursorScreenPos();
    const float h = 8.0f * s;
    ImDrawList* dl = ImGui::GetWindowDrawList();
    dl->AddRectFilled(pos, pos + ImVec2{width, h}, u32(pal.surfaceHi), h * 0.5f);
    if (shown > 0.0f) dl->AddRectFilled(pos, pos + ImVec2{std::max(h, width * shown), h}, u32(color), h * 0.5f);
    ImGui::Dummy({width, h});
}

void badge(const char* text, ImVec4 color) {
    const float s = scale();
    ImGui::PushFont(theme::fonts().small);
    const ImVec2 pad{7.0f * s, 2.0f * s};
    const ImVec2 textSize = ImGui::CalcTextSize(text);
    const ImVec2 size = textSize + pad * 2.0f;

    // Vertically centre on a frame-height line (tables, rows with buttons).
    const float offsetY = std::max(0.0f, (ImGui::GetFrameHeight() - size.y) * 0.5f);
    const ImVec2 pos = ImGui::GetCursorScreenPos() + ImVec2{0, offsetY};
    ImDrawList* dl = ImGui::GetWindowDrawList();
    dl->AddRectFilled(pos, pos + size, u32(theme::withAlpha(color, 0.15f)), size.y * 0.5f);
    dl->AddText(pos + pad, u32(color), text);
    ImGui::Dummy({size.x, size.y + offsetY});
    ImGui::PopFont();
}

        ImGui::PopTextWrapPos();

    }
}

bool colorSwatches(const char* id, std::span<const ImVec4> colors, int& current) {
    const float s = scale();
    const float r = 11.0f * s;
    bool changed = false;

    ImGui::PushID(id);
    for (int i = 0; i < static_cast<int>(colors.size()); ++i) {
        if (i > 0) ImGui::SameLine(0, 10.0f * s);
        ImGui::PushID(i);
        const ImVec2 pos = ImGui::GetCursorScreenPos();
        if (ImGui::InvisibleButton("##swatch", {r * 2 + 6 * s, r * 2 + 6 * s}) && current != i) {
            current = i;
            changed = true;
        }
        const bool hovered = ImGui::IsItemHovered();
        const float sel = animate(ImGui::GetID("sel"), current == i ? 1.0f : 0.0f);
        ImGui::PopID();

        const ImVec2 c = pos + ImVec2{r + 3 * s, r + 3 * s};
        ImDrawList* dl = ImGui::GetWindowDrawList();
        dl->AddCircleFilled(c, r * (hovered ? 1.0f : 0.9f), u32(colors[static_cast<std::size_t>(i)]), 32);
        if (sel > 0.01f) {
            dl->AddCircle(c, r + 2.0f * s, IM_COL32(255, 255, 255, static_cast<int>(220 * sel)), 32, 2.0f * s);
            dl->AddCircleFilled(c, r * 0.32f * sel, IM_COL32(255, 255, 255, 255), 16);
        }
    }
    ImGui::PopID();
    return changed;
}

void MainWindow::draw(const core::AppState& state, core::ActionSink& actions) {
    const auto& pal = theme::palette();
    const ImGuiViewport* viewport = ImGui::GetMainViewport();

    ImGui::SetNextWindowPos(viewport->WorkPos);
    ImGui::SetNextWindowSize(viewport->WorkSize);
    ImGui::PushStyleVar(ImGuiStyleVar_WindowPadding, {0, 0});
    ImGui::PushStyleVar(ImGuiStyleVar_WindowRounding, 0.0f);
    constexpr ImGuiWindowFlags kRootFlags = ImGuiWindowFlags_NoDecoration | ImGuiWindowFlags_NoMove |
                                            ImGuiWindowFlags_NoSavedSettings | ImGuiWindowFlags_NoBringToFrontOnFocus;
    ImGui::Begin("##root", nullptr, kRootFlags);
    ImGui::PopStyleVar(2);

    drawSidebar();
    ImGui::SameLine(0, 0);

    // ---- Main column ----
    ImGui::PushStyleColor(ImGuiCol_ChildBg, pal.background);
    ImGui::PushStyleVar(ImGuiStyleVar_WindowPadding, ImVec2{28.0f, 22.0f} * scale());
    ImGui::BeginChild("##main", {0, 0}, ImGuiChildFlags_AlwaysUseWindowPadding);
    ImGui::PopStyleVar();
    ImGui::PopStyleColor();

    drawHeader(state);

    const float statusH = ImGui::GetFrameHeight() + ImGui::GetStyle().ItemSpacing.y;
    m_fade = theme::animationsEnabled() ? std::min(1.0f, m_fade + ImGui::GetIO().DeltaTime * 5.0f) : 1.0f;

    ImGui::PushStyleColor(ImGuiCol_ChildBg, ImVec4{0, 0, 0, 0});
    ImGui::BeginChild("##content", {0, -statusH}, ImGuiChildFlags_None);
    ImGui::PopStyleColor();
    ImGui::PushStyleVar(ImGuiStyleVar_Alpha, m_fade);
    ImGui::PushID(static_cast<int>(m_active));
    activePageRef().draw(activeSection(), state, actions);
    ImGui::PopID();
    ImGui::PopStyleVar();
    ImGui::EndChild();

    drawStatusBar(state);
    ImGui::EndChild();
    ImGui::End();

    if (state.settings.general.showFpsOverlay) drawFpsOverlay();
}

void MainWindow::drawSidebar() {
    const auto& pal = theme::palette();
    const float s = scale();
    const float width = 78.0f * s;
    const float buttonSize = 46.0f * s;

    ImGui::PushStyleColor(ImGuiCol_ChildBg, pal.sidebar);
    ImGui::PushStyleVar(ImGuiStyleVar_WindowPadding, ImVec2{0, 18.0f * s});
    ImGui::PushStyleVar(ImGuiStyleVar_ItemSpacing, ImVec2{0, 8.0f * s});
    ImGui::BeginChild("##sidebar", {width, 0}, ImGuiChildFlags_AlwaysUseWindowPadding, ImGuiWindowFlags_NoScrollbar);

    ImDrawList* dl = ImGui::GetWindowDrawList();
    const ImVec2 winPos = ImGui::GetWindowPos();
    const ImVec2 winSize = ImGui::GetWindowSize();
    dl->AddLine({winPos.x + winSize.x - 1, winPos.y}, {winPos.x + winSize.x - 1, winPos.y + winSize.y}, u32(pal.border));

    // Logo.
    const float logoSize = 30.0f * s;
    const ImVec2 logoPos = ImGui::GetCursorScreenPos() + ImVec2{(width - logoSize) * 0.5f, 0};
    drawIcon(dl, Icon::Logo, logoPos + ImVec2{logoSize, logoSize} * 0.5f, logoSize, u32(pal.accent));
    ImGui::Dummy({width, logoSize + 18.0f * s});

    auto navButton = [&](PageId id) {
        Page& page = *m_pages[static_cast<std::size_t>(id)];
        ImGui::SetCursorPosX((width - buttonSize) * 0.5f);
        if (widgets::sidebarButton(page.title(), page.icon(), m_active == id, page.title(), winPos.x))
            setActivePage(id);
    };

    for (PageId id : {PageId::Combat, PageId::Player, PageId::Inventory, PageId::Explorer}) navButton(id);

    // Settings pinned to the bottom.
    ImGui::SetCursorPosY(std::max(ImGui::GetCursorPosY(), winSize.y - buttonSize - 18.0f * s));
    navButton(PageId::Settings);

    ImGui::EndChild();
    ImGui::PopStyleVar(2);
    ImGui::PopStyleColor();
}

void MainWindow::drawStatusBar(const core::AppState& state) {
    const auto& pal = theme::palette();
    const ImVec2 p = ImGui::GetCursorScreenPos();
    const float width = ImGui::GetContentRegionAvail().x;
    const float right = ImGui::GetCursorPosX() + width;
    ImGui::GetWindowDrawList()->AddLine({p.x, p.y}, {p.x + width, p.y}, u32(pal.border));
    ImGui::SetCursorPosY(ImGui::GetCursorPosY() + ImGui::GetStyle().ItemSpacing.y);

    ImGui::AlignTextToFramePadding();
    if (!state.log.empty()) {
        const core::LogEntry& last = state.log.back();
        const float age = static_cast<float>(state.clock - last.timestamp);
        const float alpha = std::clamp(1.0f - (age - 4.0f) / 2.0f, 0.45f, 1.0f);  // dims after ~5 s
        ImVec4 dot = pal.textMuted;
        switch (last.level) {
            case core::LogLevel::Success: dot = pal.success; break;
            case core::LogLevel::Warning: dot = pal.warning; break;
            case core::LogLevel::Error: dot = pal.danger; break;
            default: break;
        }
        const float r = 3.5f * scale();
        const ImVec2 c = ImGui::GetCursorScreenPos() + ImVec2{r, ImGui::GetFrameHeight() * 0.5f};
        ImGui::GetWindowDrawList()->AddCircleFilled(c, r, u32(theme::withAlpha(dot, alpha)));
        ImGui::Dummy({r * 2.0f, 0});
        ImGui::SameLine();
        ImGui::TextColored(theme::withAlpha(pal.text, alpha * 0.85f), "%s", last.message.c_str());
    }

    const auto& ex = state.explorer;
    char info[96];
    std::snprintf(info, sizeof info, "%s   %.0f FPS",
                  ex.locations.empty() ? "-" : ex.locations[static_cast<std::size_t>(ex.currentLocation)].name.c_str(),
                  ImGui::GetIO().Framerate);
    ImGui::SameLine(0, 0);
    ImGui::SetCursorPosX(right - ImGui::CalcTextSize(info).x);
    ImGui::TextColored(pal.textMuted, "%s", info);
}

void MainWindow::drawFpsOverlay() {
    const auto& pal = theme::palette();
    const float s = scale();
    char text[32];
    std::snprintf(text, sizeof text, "%.0f FPS  %.2f ms", ImGui::GetIO().Framerate, 1000.0f / ImGui::GetIO().Framerate);

    const ImGuiViewport* vp = ImGui::GetMainViewport();
    const ImVec2 pad{10.0f * s, 6.0f * s};

    const ImVec2 pos{vp->WorkPos.x + vp->WorkSize.x - size.x - 12.0f * s, vp->WorkPos.y + 12.0f * s};

    ImDrawList* dl = ImGui::GetForegroundDrawList();
    dl->AddRectFilled(pos, pos + size, u32(theme::withAlpha(pal.sidebar, 0.92f)), size.y * 0.5f);
    dl->AddRect(pos, pos + size, u32(pal.border), size.y * 0.5f);
    dl->AddText(pos + pad, u32(pal.success), text);
}

bool containsIgnoreCase(std::string_view haystack, std::string_view needle) {
    if (needle.empty()) return true;
    const auto it = std::ranges::search(haystack, needle, [](char a, char b) {
        return std::tolower(static_cast<unsigned char>(a)) == std::tolower(static_cast<unsigned char>(b));
    });
    return !it.empty();
}

const char* useLabel(const core::Item& item) {
    switch (item.category) {
        case core::ItemCategory::Weapon:
        case core::ItemCategory::Armor: return item.equipped ? "Unequip" : "Equip";
        case core::ItemCategory::Consumable: return "Use";
        default: return nullptr;
    }
}

void InventoryPage::drawItems(const core::AppState& state, core::ActionSink& actions) {
    using namespace widgets;
    const auto& pal = theme::palette();
    const auto& inv = state.inventory;
    const float s = ImGui::GetIO().FontGlobalScale;

    Card card("Backpack", "Use, equip or drop items. Quest items are protected.");

    // ---- Toolbar ----
    ImGui::SetNextItemWidth(200.0f * s);
    ImGui::InputTextWithHint("##search", "Search items...", m_search, sizeof m_search);
    ImGui::SameLine();
    ImGui::SetNextItemWidth(150.0f * s);
    ImGui::Combo("##category", &m_categoryFilter, kCategoryFilter.data(), static_cast<int>(kCategoryFilter.size()));
    ImGui::SameLine();

    core::InventoryPrefs prefs = inv.prefs;
    ImGui::SetNextItemWidth(120.0f * s);
    bool prefsChanged = ImGui::Combo("##sort", &prefs.sortMode, core::kSortModes.data(), static_cast<int>(core::kSortModes.size()));
    ImGui::SetItemTooltip("Sort by");
    ImGui::SameLine();
    if (button(prefs.sortDescending ? "Desc" : "Asc")) {
        prefs.sortDescending = !prefs.sortDescending;
        prefsChanged = true;
    }
    if (prefsChanged) actions.dispatch(core::action::UpdateInventoryPrefs{prefs});

    const char* lootLabel = "+ Loot random item";
    const float lootW = ImGui::CalcTextSize(lootLabel).x + ImGui::GetStyle().FramePadding.x * 2.0f;
    ImGui::SameLine(0, 0);
    ImGui::SetCursorPosX(std::max(ImGui::GetCursorPosX() + ImGui::GetStyle().ItemSpacing.x,
                                  ImGui::GetCursorPosX() + ImGui::GetContentRegionAvail().x - lootW));
    if (button(lootLabel, ButtonKind::Primary)) actions.dispatch(core::action::SpawnRandomItem{});

    ImGui::Spacing();
    const float weight = core::totalWeight(inv);
    statBar("Carry weight (kg)", weight, inv.maxWeight, weight > inv.maxWeight * 0.85f ? pal.danger : pal.accent);
    ImGui::Spacing();

    // ---- Table ----
    constexpr ImGuiTableFlags kFlags = ImGuiTableFlags_RowBg | ImGuiTableFlags_BordersInnerH |
                                       ImGuiTableFlags_SizingStretchProp | ImGuiTableFlags_PadOuterX;
    if (ImGui::BeginTable("##items", 6, kFlags)) {
        ImGui::TableSetupColumn("Item", ImGuiTableColumnFlags_WidthStretch, 3.0f);
        ImGui::TableSetupColumn("Category", ImGuiTableColumnFlags_WidthStretch, 1.4f);
        ImGui::TableSetupColumn("Rarity", ImGuiTableColumnFlags_WidthStretch, 1.4f);
        ImGui::TableSetupColumn("Qty", ImGuiTableColumnFlags_WidthStretch, 0.7f);
        ImGui::TableSetupColumn("Weight", ImGuiTableColumnFlags_WidthStretch, 1.0f);
        ImGui::TableSetupColumn("##actions", ImGuiTableColumnFlags_WidthFixed, 160.0f * s);
        ImGui::TableHeadersRow();

        int shown = 0;
        for (const core::Item& item : inv.items) {
            if (m_categoryFilter > 0 && static_cast<int>(item.category) != m_categoryFilter - 1) continue;
            if (!containsIgnoreCase(item.name, m_search)) continue;
            ++shown;

            ImGui::PushID(item.id);
            ImGui::TableNextRow(ImGuiTableRowFlags_None, ImGui::GetFrameHeightWithSpacing());
            const ImVec4 rarity = theme::rarityColor(item.rarity);

            ImGui::TableNextColumn();
            {
                const ImVec2 p = ImGui::GetCursorScreenPos();
                const float h = ImGui::GetFrameHeight();
                ImGui::GetWindowDrawList()->AddCircleFilled(p + ImVec2{4.0f * s, h * 0.5f}, 4.0f * s,
                                                            ImGui::ColorConvertFloat4ToU32(rarity));
                ImGui::SetCursorScreenPos(p + ImVec2{14.0f * s, 0});
                ImGui::AlignTextToFramePadding();
                ImGui::TextUnformatted(item.name.c_str());
                if (item.equipped) {
                    ImGui::SameLine();
                    badge("Equipped", pal.accent);
                }
            }

            ImGui::TableNextColumn();
            ImGui::AlignTextToFramePadding();
            ImGui::TextColored(pal.textMuted, "%s", core::kItemCategoryNames[static_cast<std::size_t>(item.category)]);

            ImGui::TableNextColumn();
            badge(core::kRarityNames[static_cast<std::size_t>(item.rarity)], rarity);

            ImGui::TableNextColumn();
            ImGui::AlignTextToFramePadding();
            ImGui::Text("x%d", item.quantity);

            ImGui::TableNextColumn();
            ImGui::AlignTextToFramePadding();
            ImGui::TextColored(pal.textMuted, "%.1f kg", item.weight * static_cast<float>(item.quantity));

            ImGui::TableNextColumn();
            if (const char* label = useLabel(item)) {
                if (button(label, ButtonKind::Secondary, {80.0f * s, 0})) actions.dispatch(core::action::UseItem{item.id});
                ImGui::SameLine();
            }
            if (button("Drop", ButtonKind::Danger)) {
                if (inv.prefs.confirmDrop) m_pendingDropId = item.id;
                else actions.dispatch(core::action::DropItem{item.id});
            }
            ImGui::PopID();
        }
        ImGui::EndTable();

        if (shown == 0) caption("No items match the current filter.");
    }

    // ---- Confirmation modal (opened outside the per-row ID scope) ----
    if (m_pendingDropId != -1 && !ImGui::IsPopupOpen("Drop item?")) ImGui::OpenPopup("Drop item?");
    ImGui::SetNextWindowPos(ImGui::GetMainViewport()->GetCenter(), ImGuiCond_Appearing, {0.5f, 0.5f});
    if (ImGui::BeginPopupModal("Drop item?", nullptr, ImGuiWindowFlags_AlwaysAutoResize)) {
        const auto it = std::ranges::find(inv.items, m_pendingDropId, &core::Item::id);
        if (it == inv.items.end()) {
            m_pendingDropId = -1;
            ImGui::CloseCurrentPopup();
        } else {
            ImGui::Text("Drop %s x%d?", it->name.c_str(), it->quantity);
            caption("Dropped items are gone for good.");
            ImGui::Spacing();
            if (button("Drop", ButtonKind::Danger, {110.0f * s, 0})) {
                actions.dispatch(core::action::DropItem{m_pendingDropId});
                m_pendingDropId = -1;
                ImGui::CloseCurrentPopup();
            }
            ImGui::SameLine();
            if (button("Cancel", ButtonKind::Secondary, {110.0f * s, 0}) || ImGui::IsKeyPressed(ImGuiKey_Escape)) {
                m_pendingDropId = -1;
                ImGui::CloseCurrentPopup();
            }
        }
        ImGui::EndPopup();
    }
}

void ExplorerPage::drawLocations(const core::AppState& state, core::ActionSink& actions) {
    using namespace widgets;
    const auto& pal = theme::palette();
    const auto& ex = state.explorer;
    if (ex.locations.empty()) return;

    m_selected = std::clamp(m_selected, 0, static_cast<int>(ex.locations.size()) - 1);
    const core::Vec3& here = ex.locations[static_cast<std::size_t>(ex.currentLocation)].position;

    CardGrid grid("##explorer", 300.0f);
    {
        Card card("Known locations", "Double-click to travel. Your location is highlighted.");
        checkbox("Only discovered", &m_onlyDiscovered);

        constexpr ImGuiTableFlags kFlags = ImGuiTableFlags_RowBg | ImGuiTableFlags_SizingStretchProp;
        if (ImGui::BeginTable("##locations", 3, kFlags)) {
            ImGui::TableSetupColumn("Name", ImGuiTableColumnFlags_WidthStretch, 2.2f);
            ImGui::TableSetupColumn("Region", ImGuiTableColumnFlags_WidthStretch, 1.5f);
            ImGui::TableSetupColumn("Distance", ImGuiTableColumnFlags_WidthStretch, 1.0f);
            ImGui::TableHeadersRow();

            for (int i = 0; i < static_cast<int>(ex.locations.size()); ++i) {
                const core::Location& loc = ex.locations[static_cast<std::size_t>(i)];
                if (m_onlyDiscovered && !loc.discovered) continue;

                ImGui::PushID(i);
                ImGui::TableNextRow();
                ImGui::TableNextColumn();

                const bool isHere = i == ex.currentLocation;
                ImGui::PushStyleColor(ImGuiCol_Text, isHere ? pal.accent : loc.discovered ? pal.text : pal.textDisabled);
                const char* name = loc.discovered ? loc.name.c_str() : "???";
                if (ImGui::Selectable(name, m_selected == i, ImGuiSelectableFlags_SpanAllColumns | ImGuiSelectableFlags_AllowDoubleClick)) {
                    m_selected = i;
                    if (ImGui::IsMouseDoubleClicked(ImGuiMouseButton_Left)) actions.dispatch(core::action::TeleportTo{i});
                }
                ImGui::PopStyleColor();
                if (isHere) ImGui::SetItemTooltip("You are here");

                ImGui::TableNextColumn();
                ImGui::TextColored(pal.textMuted, "%s", loc.region.c_str());
                ImGui::TableNextColumn();
                ImGui::TextColored(pal.textMuted, "%.0f m", core::distance(here, loc.position));
                ImGui::PopID();
            }
            ImGui::EndTable();
        }
    }
    grid.next();
    {
        const core::Location& loc = ex.locations[static_cast<std::size_t>(m_selected)];
        const bool isHere = m_selected == ex.currentLocation;

        Card card("Details");
        ImGui::PushFont(theme::fonts().heading);
        ImGui::TextUnformatted(loc.discovered ? loc.name.c_str() : "Undiscovered");
        ImGui::PopFont();
        caption(loc.region.c_str());
        ImGui::Spacing();

        if (isHere) badge("Current location", pal.accent);
        else if (loc.discovered) badge("Discovered", pal.success);
        else badge("Hidden", pal.warning);

        ImGui::Spacing();
        ImGui::TextColored(pal.textMuted, "Coordinates");
        ImGui::Text("%.0f, %.0f, %.0f", loc.position.x, loc.position.y, loc.position.z);
        ImGui::TextColored(pal.textMuted, "Distance");
        ImGui::Text("%.0f m", core::distance(here, loc.position));
        ImGui::Spacing();

        ImGui::BeginDisabled(!loc.discovered || isHere);
        if (button("Fast travel", ButtonKind::Primary)) actions.dispatch(core::action::TeleportTo{m_selected});
        ImGui::EndDisabled();
        ImGui::SameLine();
        if (button("Reveal all")) actions.dispatch(core::action::RevealAllLocations{});
    }
}

void testController() {
    core::AppState state = core::makeDemoState();
    core::Controller controller(state);
    using namespace core::action;

    // Values are validated before being committed.
    core::CombatSettings combat = state.combat;
    combat.attackSpeed = 99.0f;
    combat.difficulty = 42;
    controller.handle(UpdateCombat{combat});
    CHECK(state.combat.attackSpeed == 3.0f);
    CHECK(state.combat.difficulty == static_cast<int>(core::kDifficulties.size()) - 1);

    // Consumables heal and are consumed.
    state.player.health = 10.0f;
    const auto potion = std::ranges::find(state.inventory.items, std::string("Health Potion"), &core::Item::name);
    CHECK(potion != state.inventory.items.end());
    const int potionId = potion->id, potionQty = potion->quantity;
    controller.handle(UseItem{potionId});
    CHECK(state.player.health > 10.0f);
    CHECK(std::ranges::find(state.inventory.items, potionId, &core::Item::id)->quantity == potionQty - 1);

    // Quest items can't be dropped, others can.
    const auto quest = std::ranges::find(state.inventory.items, core::ItemCategory::Quest, &core::Item::category);
    const std::size_t count = state.inventory.items.size();
    controller.handle(DropItem{quest->id});
    CHECK(state.inventory.items.size() == count);
    controller.handle(DropItem{potionId});
    CHECK(state.inventory.items.size() == count - 1);

    // Only discovered locations are reachable.
    const auto hidden = std::ranges::find(state.explorer.locations, false, &core::Location::discovered);
    const int hiddenIndex = static_cast<int>(hidden - state.explorer.locations.begin());
    controller.handle(TeleportTo{hiddenIndex});
    CHECK(state.explorer.currentLocation == 0);
    controller.handle(RevealAllLocations{});
    controller.handle(TeleportTo{hiddenIndex});
    CHECK(state.explorer.currentLocation == hiddenIndex);

    // Appearance changes are broadcast.
    int notified = 0;
    controller.onAppearanceChanged = [&](const core::AppearanceSettings&) { ++notified; };
    core::AppearanceSettings appearance = state.settings.appearance;
    appearance.accent = 2;
    controller.handle(UpdateAppearance{appearance});
    controller.handle(UpdateAppearance{appearance});  // unchanged -> no notification
    CHECK(notified == 1);

    // Time advances unless frozen.
    const float t0 = state.explorer.world.timeOfDay;
    controller.tick(1.0f);
    CHECK(state.explorer.world.timeOfDay != t0);
    state.explorer.world.freezeTime = true;
    const float t1 = state.explorer.world.timeOfDay;
    controller.tick(1.0f);
    CHECK(state.explorer.world.timeOfDay == t1);
}

        // Every page and every pill section renders.
        for (int p = 0; p < static_cast<int>(ui::PageId::Count); ++p) {
            application.window().setActivePage(static_cast<ui::PageId>(p));
            for (int section = 0; section < 3; ++section) {
                application.window().setActiveSection(section);
                for (int i = 0; i < 3; ++i) renderFrame(application);
                CHECK(ImGui::GetDrawData()->TotalVtxCount > 0);
            }
        }

        // Narrow window -> single-column layout still works.
        io.DisplaySize = {560, 700};
        for (int i = 0; i < 3; ++i) renderFrame(application);
        io.DisplaySize = {1280, 800};

        // Clicking the third sidebar icon navigates to Inventory.
        application.window().setActivePage(ui::PageId::Combat);
        renderFrame(application);
        io.AddMousePosEvent(39.0f, 205.0f);
        renderFrame(application);
        io.AddMouseButtonEvent(ImGuiMouseButton_Left, true);
        renderFrame(application);
        io.AddMouseButtonEvent(ImGuiMouseButton_Left, false);
        renderFrame(application);
        CHECK(application.window().activePage() == ui::PageId::Inventory);
    }

    ImGui::DestroyContext();
}

# Nova Panel — современный интерфейс на Dear ImGui (C++20)

Тёмная тема, боковая панель с векторными иконками, вкладки-«пилюли» с анимированным
переключением и пять разделов: **Combat, Player, Inventory, Explorer, Settings**.

## Сборка

Нужны CMake ≥ 3.20, компилятор с C++20 (GCC 13+, Clang 16+, MSVC 2022) и OpenGL.
ImGui (v1.91.9) скачивается автоматически; GLFW берётся из системы, а если его нет — тоже скачивается.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/nova_panel
```

Тесты работают без окна и без GPU:

```bash
ctest --test-dir build --output-on-failure
```

## Архитектура

```
src/
├── core/                 ← модель и логика, НЕ зависят от ImGui
│   ├── AppState.h/.cpp   данные: настройки, предметы, локации, журнал
│   ├── Actions.h         std::variant всех действий + ActionQueue
│   └── Controller.h/.cpp единственное место, где меняется AppState
├── ui/                   ← только отрисовка
│   ├── Theme.h/.cpp      палитра, ImGuiStyle, шрифты
│   ├── Icons.h/.cpp      векторные иконки через ImDrawList
│   ├── Widgets.h/.cpp    toggle, pillTabs, sidebarButton, Card, CardGrid…
│   ├── MainWindow.h/.cpp сайдбар + заголовок + пилюли + контент + статус-бар
│   └── pages/            по одному классу на вкладку (интерфейс Page)
├── app/Application.*     связывает core и ui, задаёт порядок кадра
└── main.cpp              платформа: GLFW + OpenGL3
```

Поток данных за кадр (однонаправленный):

```
Controller::tick(dt) ──► MainWindow::draw(const AppState&, ActionSink&) ──► Controller::process(queue)
     симуляция              чтение состояния, намерения → actions          применение + валидация
```

* **Страницы только читают** `const core::AppState&`. Чтобы что-то поменять, страница
  правит *черновик* (копию блока настроек) и отправляет `action::UpdateCombat{draft}`
  либо команду (`UseItem`, `TeleportTo`, `ResetAllSettings`, …).
* **Controller** проверяет и ограничивает значения (`std::clamp`), реализует
  бизнес-правила (квестовые предметы нельзя выбросить, в неоткрытую локацию нельзя
  переместиться, зелья лечат игрока), пишет журнал событий.
* Действия копятся в `ActionQueue` и применяются **после** отрисовки, поэтому
  весь кадр видит согласованное состояние.
* Чисто визуальное состояние (строка поиска, выбранная пилюля, открытый модальный диалог)
  живёт во view — в доменную модель оно не попадает.
* Смена темы идёт через наблюдатель `Controller::onAppearanceChanged` → `theme::apply()`.

Добавить новую вкладку: класс-наследник `ui::Page` в `src/ui/pages/`, новый `PageId`
и строка в конструкторе `MainWindow`.

## Параметры стиля (`ui::theme::apply`)

| Параметр | Значение | | Цвет | Значение |
|---|---|---|---|---|
| `WindowRounding` | radius + 4 | | `WindowBg` | `#0D0E12` |
| `ChildRounding` | radius + 2 | | сайдбар | `#111217` |
